Quiz — Dérivation

Première STMG · chapitre 6 · 20 questions

Score : 0 / 20

1Le nombre dérivé $f'(a)$ est le coefficient directeur :

Réponse : C'est l'interprétation graphique du nombre dérivé.

2La dérivée de la fonction $x\mapsto x^{2}$ est :

Réponse : $\left(x^{2}\right)'=2x$.

3La dérivée de $f(x)=3x^{2}$ est :

Réponse : $3\times2x=6x$.

4La dérivée de $f(x)=5x$ est :

Réponse : La dérivée de $ax+b$ est $a$.

5La dérivée de la fonction constante $f(x)=7$ est :

Réponse : Une constante a une dérivée nulle.

6La tangente à la courbe de $f$ en $a$ a pour équation :

Réponse : Droite passant par $A(a\,;f(a))$ de coefficient directeur $f'(a)$.

7Pour $f(x)=x^{2}$, le nombre dérivé $f'(2)$ vaut :

Réponse : $f'(x)=2x$, donc $f'(2)=4$.

8Si $f'(x)>0$ sur un intervalle, alors $f$ est sur cet intervalle :

Réponse : Le signe de la dérivée donne le sens de variation.

9Si $f'(x)<0$ sur un intervalle, alors $f$ est sur cet intervalle :

Réponse : Une dérivée négative traduit une fonction qui descend.

10Pour $f(x)=x^{2}-4x$, la dérivée est :

Réponse : $(x^{2})'=2x$ et $(-4x)'=-4$.

11Pour $f(x)=x^{2}$, le nombre dérivé $f'(3)$ vaut :

Réponse : $f'(x)=2x$, donc $f'(3)=6$.

12La tangente à une courbe est horizontale lorsque :

Réponse : Un coefficient directeur nul donne une tangente horizontale.

13La dérivée de $f(x)=(x+1)^{2}$ est :

Réponse : $f(x)=x^{2}+2x+1$, donc $f'(x)=2x+2=2(x+1)$.

14Pour $f(x)=-x^{2}+2x$, la dérivée est :

Réponse : $(-x^{2})'=-2x$ et $(2x)'=2$.

15La dérivée de $f(x)=x^{3}$ est :

Réponse : $\left(x^{3}\right)'=3x^{2}$.

16Si $f'(a)=0$ et si $f'$ change de signe en $a$, alors $f(a)$ est :

Réponse : La fonction change de sens de variation : c'est un extremum.

17Le nombre dérivé est la limite, quand $h$ tend vers $0$, de :

Réponse : C'est le taux d'accroissement entre $a$ et $a+h$.

18Pour $f(x)=2x^{2}-3x+1$, la dérivée est :

Réponse : $(2x^{2})'=4x$ et $(-3x)'=-3$.

19Le taux d'accroissement de $f$ entre $a$ et $a+h$ est :

Réponse : C'est le quotient utilisé pour définir le nombre dérivé.

20Pour $f(x)=x^{2}+2x$, la tangente au point d'abscisse $0$ a pour équation :

Réponse : $f(0)=0$ et $f'(0)=2$ : $y=2(x-0)+0=2x$.
