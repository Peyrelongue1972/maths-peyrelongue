Quiz — Primitives

Terminale spécialité · chapitre 7 · 20 questions

Score : 0 / 20

1$F$ est une primitive de $f$ sur un intervalle $I$ lorsque :

Réponse : C'est la définition d'une primitive.

2Une primitive de $f(x)=x^{2}$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $\dfrac{x^{3}}{3}$ est $x^{2}$.

3Une primitive de $f(x)=2x$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $x^{2}$ est $2x$.

4Une primitive de $f(x)=\dfrac{1}{x}$ sur $]0\,;+\infty[$ est :

Réponse : La dérivée de $\ln x$ est $\dfrac{1}{x}$.

5Une primitive de $f(x)=\mathrm{e}^{x}$ sur $\mathbb{R}$ est :

Réponse : L'exponentielle est sa propre dérivée.

6Une primitive de $f(x)=\cos(x)$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $\sin x$ est $\cos x$.

7Une primitive de $f(x)=\sin(x)$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $-\cos x$ est $\sin x$.

8Deux primitives d'une même fonction sur un intervalle diffèrent :

Réponse : Si $F'=f$ et $G'=f$, alors $(G-F)'=0$ : $G-F$ est constante.

9Une primitive de $f(x)=\dfrac{1}{x^{2}}$ sur $]0\,;+\infty[$ est :

Réponse : La dérivée de $-\dfrac{1}{x}$ est $\dfrac{1}{x^{2}}$.

10Une primitive de $f(x)=\mathrm{e}^{2x}$ sur $\mathbb{R}$ est :

Réponse : En dérivant $\dfrac{1}{2}\mathrm{e}^{2x}$ on obtient $\mathrm{e}^{2x}$.

11Une primitive de $f(x)=3x^{2}$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $x^{3}$ est $3x^{2}$.

12Une primitive de $f(x)=x$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $\dfrac{x^{2}}{2}$ est $x$.

13Pour tout $x>0$, une primitive de $f(x)=\dfrac{1}{\sqrt{x}}$ est :

Réponse : La dérivée de $2\sqrt{x}$ est $\dfrac{1}{\sqrt{x}}$.

14La fonction $F(x)=x^{3}+5$ est une primitive de :

Réponse : La constante disparaît à la dérivation.

15Parmi deux primitives d'une même fonction, celle qui vérifie $F(2)=7$ :

Réponse : La condition initiale fixe la constante.

16Une primitive de $f(x)=\mathrm{e}^{-x}$ est :

Réponse : La dérivée de $-\mathrm{e}^{-x}$ est $\mathrm{e}^{-x}$.

17Une primitive de $f(x)=x^{n}$ (pour $n\neq-1$) est :

Réponse : On augmente l'exposant d'une unité et on divise.

18Une primitive de $f(x)=(2x+1)^{3}$ est :

Réponse : On dérive $\dfrac{u^{4}}{8}$ avec $u=2x+1$, $u'=2$.

19Le calcul des primitives permet de :

Réponse : $\displaystyle\int_a^b f(t)\,\mathrm{d}t=F(b)-F(a)$.

20Une primitive de $f(x)=2$ sur $\mathbb{R}$ est :

Réponse : La dérivée de $2x$ est $2$.
