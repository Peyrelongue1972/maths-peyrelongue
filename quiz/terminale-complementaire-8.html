1L'épreuve de Bernoulli est une expérience :

Réponse : Succès de probabilité $p$, échec de probabilité $1-p$.

2Dans une loi binomiale $\mathcal{B}(n\,;p)$, $n$ désigne :

Réponse : Schéma de Bernoulli répété $n$ fois.

3$P(X=k)$ pour $X\sim\mathcal{B}(n\,;p)$ vaut :

Réponse : Formule de la loi binomiale.

4L'espérance de $X\sim\mathcal{B}(n\,;p)$ est :

Réponse : $E(X)=np$.

5La variance de $X\sim\mathcal{B}(n\,;p)$ est :

Réponse : $V(X)=np(1-p)$.

6$X\sim\mathcal{B}(10\,;0{,}3)$. $E(X)$ vaut :

Réponse : $10\times0{,}3=3$.

7$X\sim\mathcal{B}(10\,;0{,}3)$. $V(X)$ vaut :

Réponse : $10\times0{,}3\times0{,}7=2{,}1$.

8Une loi de Poisson modélise :

Réponse : Loi de Poisson de paramètre $\lambda$.

9Pour $X\sim\mathcal{P}(\lambda)$, $P(X=k)$ vaut :

Réponse : Formule de la loi de Poisson.

10Pour $X\sim\mathcal{P}(\lambda)$, $E(X)$ vaut :

Réponse : Espérance et variance valent $\lambda$.

11La loi uniforme discrète sur $\{1\,;\dots\,;n\}$ a pour espérance :

Réponse : Moyenne des valeurs.

12Pour $X\sim\mathcal{B}(5\,;0{,}5)$, $P(X=0)$ vaut :

Réponse : $(0{,}5)^{5}=\dfrac{1}{32}$.

13$P(X\leqslant k)$ se calcule :

Réponse : On somme les probabilités des valeurs $0$ à $k$.

14$n$ épreuves identiques et indépendantes ⟹ la loi du nombre de succès est :

Réponse : Schéma de Bernoulli.

15La loi binomiale est dite :

Réponse : Elle prend un nombre fini de valeurs.

16$X\sim\mathcal{B}(20\,;0{,}4)$. Le nombre moyen de succès est :

Réponse : $20\times0{,}4=8$.

17Deux lois binomiales de même $p$ mais de $n$ différents :

Réponse : $E$ et $V$ dépendent de $n$.

18L'écart-type de $\mathcal{B}(n\,;p)$ vaut :

Réponse : Racine carrée de la variance.

19Pour $\lambda=2$, $P(X=0)$ en loi de Poisson vaut :

Réponse : $\mathrm{e}^{-2}\dfrac{2^{0}}{0!}=\mathrm{e}^{-2}$.

20Le succès d'un schéma de Bernoulli est de probabilité :

Réponse : Épreuves identiques : même $p$.
