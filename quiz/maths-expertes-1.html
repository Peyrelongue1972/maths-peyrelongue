1$i^{2}$ vaut :

Réponse : Par définition, $i^2=-1$.

2La forme algébrique de $z=3-2i$ a pour partie réelle :

Réponse : Partie réelle $\mathrm{Re}(z)=3$, partie imaginaire $-2$.

3$\mathrm{Re}((2+i)(1-i))$ vaut :

Réponse : $(2+i)(1-i)=2-2i+i-i^{2}=3-i$, donc $\mathrm{Re}=3$.

4Le conjugué de $3+4i$ est :

Réponse : $\bar z=3-4i$.

5$|3+4i|$ vaut :

Réponse : $\sqrt{9+16}=5$.

6$z\bar z$ vaut :

Réponse : $z\bar z=a^{2}+b^{2}=|z|^{2}$.

7L'inverse de $1+i$ sous forme algébrique est :

Réponse : $\dfrac{1}{1+i}=\dfrac{1-i}{(1+i)(1-i)}=\dfrac{1-i}{2}$.

8Le module de $-2i$ vaut :

Réponse : $|-2i|=2$.

9$i^{4}$ vaut :

Réponse : $i^{4}=(i^{2})^{2}=1$.

10$i^{2023}$ vaut :

Réponse : $2023=4\times505+3$, donc $i^{2023}=i^{3}=-i$.

11$z=\sqrt3+i$. Un argument de $z$ est :

Réponse : $|z|=2$, $\cos\theta=\dfrac{\sqrt3}{2}$ et $\sin\theta=\dfrac12$ : $\theta=\dfrac{\pi}{6}$.

12$|z_1z_2|$ vaut :

Réponse : Le module est multiplicatif.

13$\arg(z_1z_2)$ vaut :

Réponse : Les arguments s'additionnent (modulo $2\pi$).

14Deux complexes non nuls sont égaux si et seulement si :

Réponse : Forme polaire : $z=re^{i\theta}$.

15$e^{i\pi}$ vaut :

Réponse : Formule d'Euler.

16La forme exponentielle de $i$ est :

Réponse : $i$ a pour module $1$ et pour argument $\dfrac{\pi}{2}$.

17L'équation $z^{2}=-4$ a pour solutions :

Réponse : $z^{2}=-4\iff z=\pm2i$.

18Dans $\C$, une équation du second degré a :

Réponse : Le discriminant négatif donne deux solutions complexes conjuguées.

19$z^{2}-2z+5=0$ a pour solutions :

Réponse : $\Delta=-16$, racines $\dfrac{2\pm4i}{2}=1\pm2i$.

20Si $z$ est racine d'un polynôme à coefficients réels, alors :

Réponse : La conjugaison conserve les coefficients réels.
