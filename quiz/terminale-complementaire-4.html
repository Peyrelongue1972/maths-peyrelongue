Quiz — Continuité et convexité

Terminale complémentaire · chapitre 4 · 20 questions

Score : 0 / 20

1Une fonction continue sur un intervalle est une fonction :

Réponse : Intuitivement, la courbe n'a pas de « saut ».

2Sur un intervalle, une fonction dérivable est :

Réponse : La dérivabilité implique la continuité (la réciproque est fausse).

3La fonction $x\mapsto|x|$ est continue sur $\R$ et :

Réponse : Elle présente une pointe en $0$ : pas de dérivée en $0$.

4Le théorème des valeurs intermédiaires affirme que si $f$ est continue sur $[a\,;b]$ :

Réponse : C'est l'énoncé du TVI.

5Si $f$ est continue, strictement monotone sur $[a\,;b]$ et $f(a)f(b)<0$, l'équation $f(x)=0$ admet :

Réponse : TVI + monotonie stricte donnent l'unicité.

6$f(x)=x^{3}+x-1$. $f$ est strictement croissante car :

Réponse : La dérivée est strictement positive sur $\R$.

7Une fonction est concave sur $I$ si :

Réponse : Concave : la courbe est en dessous des cordes.

8$f$ est convexe sur $I$ si et seulement si :

Réponse : Convexité ⟺ dérivée croissante ⟺ $f''\geqslant0$ (si $f$ deux fois dérivable).

9$f(x)=x^{2}$ est :

Réponse : $f''(x)=2>0$ : la fonction est convexe.

10$f(x)=\ln x$ est :

Réponse : $f''(x)=-\dfrac{1}{x^{2}}<0$.

11Un point d'inflexion est un point où :

Réponse : La courbe traverse sa tangente.

12Si $f''$ s'annule en changeant de signe en $a$, alors :

Réponse : C'est la caractérisation d'un point d'inflexion.

13$f(x)=\mathrm{e}^{x}$ est :

Réponse : $f''(x)=\mathrm{e}^{x}>0$.

14Si $f'$ s'annule en changeant de signe de $+$ à $-$, alors $f$ admet :

Réponse : Croissante puis décroissante : maximum.

15$f(x)=x^{3}$. En $0$ :

Réponse : $f''(x)=6x$ change de signe en $0$ : point d'inflexion (tangente horizontale).

16Le TVI nécessite l'hypothèse de :

Réponse : Sans continuité, le théorème est faux.

17Si $f$ est convexe sur $I$, sa courbe est :

Réponse : Propriété caractéristique de la convexité.

18Pour résoudre $f(x)=k$ par balayage, on utilise :

Réponse : Le TVI permet d'encadrer la solution, la monotonie assure l'unicité.

19$f(x)=\dfrac{1}{x}$ sur $]0\,;+\infty[$ est :

Réponse : $f''(x)=\dfrac{2}{x^{3}}>0$ pour $x>0$.

20Une fonction affine est :

Réponse : $f''=0$ : les deux inégalités de convexité sont des égalités.
