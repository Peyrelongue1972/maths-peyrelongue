Quiz — Probabilités

Seconde · chapitre 11 · 20 questions

Score : 0 / 20

1L'univers d'une expérience aléatoire est :

Réponse : C'est l'ensemble de tous les résultats possibles.

2La probabilité de l'univers $\Omega$ vaut :

Réponse : L'univers contient toutes les issues : sa probabilité est $1$.

3En situation d'équiprobabilité, la probabilité d'un événement est :

Réponse : C'est la formule de Laplace.

4On lance un dé équilibré. La probabilité d'obtenir $3$ est :

Réponse : Une seule issue favorable sur six possibles.

5On lance un dé équilibré. La probabilité d'obtenir un nombre pair est :

Réponse : Il y a trois issues favorables : $2$, $4$ et $6$.

6Pour tout événement $A$, $P\left(\overline{A}\right)$ vaut :

Réponse : Un événement et son contraire sont complémentaires.

7Si $A$ et $B$ sont incompatibles, alors $P(A\cup B)$ vaut :

Réponse : Comme $A\cap B=\varnothing$, on additionne les probabilités.

8Pour deux événements quelconques, $P(A\cup B)$ vaut :

Réponse : On retire l'intersection comptée deux fois.

9La probabilité de l'événement impossible est :

Réponse : L'événement impossible ne contient aucune issue.

10Deux événements sont incompatibles lorsque :

Réponse : Autrement dit $A\cap B=\varnothing$.

11On lance deux dés équilibrés. La probabilité d'obtenir une somme égale à $12$ est :

Réponse : Une seule issue favorables : $(6\,;6)$ sur $36$ couples possibles.

12Pour tout événement $A$, on a :

Réponse : Une probabilité est comprise entre $0$ et $1$.

13On lance un dé équilibré. La probabilité d'obtenir un nombre supérieur à $4$ est :

Réponse : Deux issues favorables : $5$ et $6$, soit $\dfrac{2}{6}=\dfrac{1}{3}$.

14Dans un jeu de $32$ cartes, la probabilité de tirer un roi est :

Réponse : Quatre rois sur $32$ cartes : $\dfrac{4}{32}=\dfrac{1}{8}$.

15Si $A$ et $B$ sont incompatibles, alors $P(A\cap B)$ vaut :

Réponse : Ils ne peuvent pas se réaliser simultanément.

16Sur un arbre, la probabilité d'un chemin est :

Réponse : On multiplie le long du chemin.

17La somme des probabilités de toutes les issues d'une expérience vaut :

Réponse : Les issues forment une partition de l'univers.

18Si $A$ est un événement certain, alors :

Réponse : Un événement certain se réalise toujours.

19Une urne contient $3$ boules rouges et $5$ boules bleues, indiscernables. La probabilité de tirer une boule rouge est :

Réponse : Trois boules rouges sur huit boules au total.

20Pour tous événements $A$ et $B$, on a :

Réponse : L'intersection est incluse dans $A$.
