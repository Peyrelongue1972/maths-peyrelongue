Quiz — Le second degré

Première STMG · chapitre 4 · 20 questions

Score : 0 / 20

1Un produit de facteurs est nul si et seulement si :

Réponse : C'est la règle du produit nul.

2Les solutions de l'équation $(x-2)(x-3)=0$ sont :

Réponse : Produit nul : $x-2=0$ ou $x-3=0$.

3Les solutions de $(2x-1)(x+3)=0$ sont :

Réponse : $2x-1=0$ donne $x=\dfrac{1}{2}$ et $x+3=0$ donne $x=-3$.

4La forme factorisée de $x^{2}-5x+6$ est :

Réponse : On cherche deux nombres de somme $5$ et de produit $6$ : $2$ et $3$.

5La forme factorisée de $x^{2}-9$ est :

Réponse : Différence de deux carrés : $a^{2}-b^{2}=(a-b)(a+b)$.

6$x^{2}+4x+4$ est égal à :

Réponse : C'est le carré d'une somme.

7$x^{2}-6x+9$ est égal à :

Réponse : C'est le carré d'une différence.

8Les solutions de $x^{2}=16$ sont :

Réponse : $x^{2}-16=0$ s'écrit $(x-4)(x+4)=0$.

9Pour résoudre $x^{2}-3x=0$, on commence par :

Réponse : $x(x-3)=0$ donne $x=0$ ou $x=3$.

10Les solutions de $x^{2}-3x=0$ sont :

Réponse : $x(x-3)=0$ : produit nul.

11La forme canonique de $x^{2}-6x+5$ est :

Réponse : $x^{2}-6x+5=(x-3)^{2}-9+5=(x-3)^{2}-4$.

12La forme canonique de $x^{2}+4x$ est :

Réponse : $x^{2}+4x=(x+2)^{2}-4$.

13Le sommet de la parabole d'équation $y=(x-3)^{2}-4$ est :

Réponse : La forme canonique donne directement le sommet $(\alpha\,;\beta)$.

14Le minimum de la fonction $f(x)=(x-2)^{2}+3$ vaut :

Réponse : $(x-2)^{2}\geqslant0$, donc $f(x)\geqslant3$.

15Le maximum de la fonction $f(x)=-(x-1)^{2}+4$ vaut :

Réponse : Le coefficient devant le carré est négatif : le sommet donne le maximum.

16Les solutions de $(x+1)^{2}=0$ sont :

Réponse : Un carré est nul seulement si le nombre est nul.

17Pour tout réel $x$, l'expression $(x-2)^{2}$ est :

Réponse : Un carré est toujours positif ou nul.

18L'expression $x^{2}+1$ :

Réponse : Une somme de carrés ne se factorise pas ; $x^{2}+1>0$ pour tout $x$.

19Le signe de $(x-2)(x-3)$ est :

Réponse : Produit de deux facteurs du premier degré : positif à l'extérieur des racines.

20L'ensemble des solutions de $(x-2)(x+5)\leqslant0$ est :

Réponse : Le produit est négatif entre ses racines $-5$ et $2$.
