Quiz — Statistique à deux variables

Terminale STMG · chapitre 9 · 20 questions

Score : 0 / 20

1Une série statistique à deux variables est une série où, pour chaque individu, on relève :

Réponse : On étudie le lien entre deux grandeurs.

2Le nuage de points d'une série à deux variables a pour coordonnées :

Réponse : Chaque individu donne un point du plan.

3Le point moyen d'un nuage a pour coordonnées :

Réponse : C'est le couple des moyennes.

4Un ajustement affine consiste à :

Réponse : On cherche une droite de régression.

5La droite de régression passe par :

Réponse : C'est une propriété de la droite des moindres carrés.

6Le coefficient de corrélation linéaire $r$ est toujours compris entre :

Réponse : C'est la définition de ce coefficient.

7Un coefficient de corrélation $r$ proche de $1$ indique :

Réponse : Les points sont alignés suivant une droite croissante.

8Un coefficient de corrélation $r$ proche de $0$ indique :

Réponse : Les points ne suivent pas de direction privilégiée.

9Un coefficient de corrélation $r=-0{,}95$ indique :

Réponse : Les points sont alignés suivant une droite décroissante.

10Une interpolation consiste à :

Réponse : On reste dans le domaine observé.

11Une extrapolation consiste à :

Réponse : La fiabilité de la prévision diminue alors.

12Si l'on a dix valeurs de $x$ dont la somme vaut $30$, alors $\overline{x}$ vaut :

Réponse : $\overline{x}=\dfrac{30}{10}=3$.

13Un ajustement affine est adapté lorsque :

Réponse : On vérifie avec le coefficient de corrélation.

14La méthode utilisée pour déterminer la droite d'ajustement est celle :

Réponse : C'est la méthode de régression.

15L'équation d'une droite d'ajustement s'écrit :

Réponse : C'est une droite, donc une fonction affine.

16Pour faire une prévision à l'aide d'un ajustement affine, on :

Réponse : On utilise l'équation de la droite.

17Avec $r=0{,}99$, on peut dire que :

Réponse : $r$ très proche de $1$.

18Dans l'équation $y=2{,}5x+10$, le coefficient $2{,}5$ représente :

Réponse : C'est le coefficient directeur.

19Prévoir à long terme par extrapolation est :

Réponse : L'ajustement n'est valable que sur la plage observée.

20Le point moyen d'un nuage $(3\,;5)$ signifie que :

Réponse : Les coordonnées sont les moyennes.
