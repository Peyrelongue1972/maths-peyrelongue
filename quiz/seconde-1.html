Quiz — Les ensembles de nombres

1$\sqrt{2}$ appartient à :

Réponse : $\sqrt{2}$ est irrationnel : il n'est pas quotient de deux entiers.

2$\dfrac{7}{3}$ est un nombre :

Réponse : C'est un quotient de deux entiers.

3Le plus petit ensemble de nombres contenant $-5$ est :

Réponse : $-5$ est un entier relatif, mais pas un entier naturel.

4$0{,}25$ est un nombre :

Réponse : $0{,}25=\dfrac{1}{4}$ a une écriture décimale finie.

5$\pi$ est un nombre :

Réponse : $\pi$ n'est pas quotient de deux entiers.

6$\dfrac{3}{4}$ est égal à :

Réponse : $3\div4=0{,}75$.

7$\sqrt{9}$ est un nombre :

Réponse : $\sqrt{9}=3$, qui est un entier naturel.

8La notation $\mathbb{N}^{*}$ désigne :

Réponse : L'étoile exclut le zéro.

9Tout entier relatif est aussi :

Réponse : $\mathbb{Z}\subset\mathbb{Q}$ : $5=\dfrac{5}{1}$.

10Parmi ces nombres, lequel est irrationnel ?

Réponse : $\sqrt{5}$ n'est pas un quotient d'entiers.

11$x\in[2\,;5]$ signifie :

Réponse : Les crochets fermés incluent les bornes.

12L'intervalle $]-\infty\,;3]$ contient :

Réponse : C'est l'ensemble des $x$ tels que $x\leqslant3$.

13Le nombre $4$ appartient-il à $[1\,;4[$ ?

Réponse : Le crochet ouvert exclut la borne.

14$0$ appartient à :

Réponse : $0$ est le premier entier naturel, mais il est exclu des ensembles étoilés.

15$-0{,}5$ est un nombre :

Réponse : $-0{,}5=-\dfrac{1}{2}$.

16$\sqrt{16}$ est égal à :

Réponse : $4^{2}=16$, donc $\sqrt{16}=4$.

17$\dfrac{2}{7}$ est un nombre :

Réponse : Son écriture décimale est infinie et périodique : ce n'est pas un décimal.

18L'ensemble $\mathbb{Q}$ est :

Réponse : Tout rationnel est un réel.

19$\dfrac{1}{3}$ est un nombre :

Réponse : C'est un quotient de deux entiers.

20$x\in]-2\,;+\infty[$ signifie :

Réponse : Le crochet est ouvert en $-2$ et l'infini est toujours ouvert.
