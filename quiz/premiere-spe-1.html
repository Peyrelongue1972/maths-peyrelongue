Quiz — Fonction du second degré

Première spécialité · chapitre 1 · 20 questions

Score : 0 / 20

1La forme canonique de $f(x)=x^{2}-4x+1$ est :

Réponse : $x^{2}-4x+1=(x-2)^{2}-4+1=(x-2)^{2}-3$.

2Le sommet de la parabole d'équation $y=2x^{2}-8x+5$ est :

Réponse : $\alpha=-\dfrac{b}{2a}=\dfrac{8}{4}=2$ et $\beta=f(2)=8-16+5=-3$.

3La parabole $y=-x^{2}+6x-5$ admet pour axe de symétrie :

Réponse : L'axe de symétrie est la droite d'équation $x=\alpha$ avec $\alpha=-\dfrac{b}{2a}=\dfrac{-6}{-2}=3$.

4Le discriminant du trinôme $2x^{2}-3x+1$ vaut :

Réponse : $\Delta=b^{2}-4ac=9-4\times2\times1=9-8=1$.

5L'équation $x^{2}+2x+5=0$ :

Réponse : $\Delta=4-20=-16<0$ : aucune solution réelle.

6Les solutions de $x^{2}-5x+6=0$ sont :

Réponse : $\Delta=25-24=1$, d'où $x=\dfrac{5\pm1}{2}$, soit $2$ et $3$.

7Le trinôme $-2x^{2}+3x-5$ est :

Réponse : $\Delta=9-40=-31<0$ et $a=-2<0$ : le trinôme est toujours du signe de $a$, donc strictement négatif.

8La forme factorisée de $x^{2}-9$ est :

Réponse : C'est une identité remarquable : $a^{2}-b^{2}=(a-b)(a+b)$ avec $a=x$ et $b=3$.

9La parabole d'équation $y=(x+1)^{2}-4$ coupe l'axe des abscisses en :

Réponse : $(x+1)^{2}=4$ donne $x+1=2$ ou $x+1=-2$, soit $x=1$ ou $x=-3$.

10Le signe de $(x-2)(x+5)$ est :

Réponse : Produit de deux facteurs du premier degré : il est positif à l'extérieur des racines $-5$ et $2$.

11L'expression $x^{2}+4x+4$ est égale à :

Réponse : $x^{2}+4x+4=(x+2)^{2}$ : carré d'une somme.

12Pour tout réel $x$, l'expression $3(x-1)^{2}+2$ est :

Réponse : $(x-1)^{2}\geqslant0$, donc $3(x-1)^{2}+2\geqslant2$.

13La fonction $f(x)=-2(x-3)^{2}+7$ atteint son maximum :

Réponse : Le coefficient $-2$ est négatif : la parabole est orientée vers le bas et le sommet $(3\,;7)$ donne le maximum.

14Le minimum de $f(x)=x^{2}-6x+11$ sur $\mathbb{R}$ est :

Réponse : $f(x)=(x-3)^{2}+2$, donc le minimum vaut $2$, atteint en $x=3$.

15Les racines de $3x^{2}-12$ sont :

Réponse : $3x^{2}=12$ donne $x^{2}=4$, donc $x=-2$ ou $x=2$.

16Si le discriminant d'un trinôme $ax^{2}+bx+c$ est nul, alors :

Réponse : $\Delta=0$ : une seule racine, dite double, $x=-\dfrac{b}{2a}$.

17Pour $x\neq2$, le signe de $x^{2}-4x+4$ est :

Réponse : $x^{2}-4x+4=(x-2)^{2}$ est toujours positif, et strictement positif sauf en $x=2$.

18La courbe de $f(x)=x^{2}+1$ se déduit de celle de $x\mapsto x^{2}$ par :

Réponse : Ajouter $1$ à l'ordonnée translate la courbe de $1$ vers le haut.

19L'ensemble des solutions de $x^{2}-1>0$ est :

Réponse : $(x-1)(x+1)>0$ : le produit est positif à l'extérieur des racines $-1$ et $1$.

20Le sommet de la parabole d'équation $y=x^{2}+2x$ est :

Réponse : $x^{2}+2x=(x+1)^{2}-1$ : le sommet est $(-1\,;-1)$.
