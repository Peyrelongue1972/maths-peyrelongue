1Dans le repère, l'abscisse du point $A(3\,;-2)$ est :

Réponse : L'abscisse est la première coordonnée.

2Dans le repère, l'ordonnée du point $A(3\,;-2)$ est :

Réponse : L'ordonnée est la seconde coordonnée.

3Le point de coordonnées $(0\,;0)$ est :

Réponse : C'est l'intersection des deux axes.

4Le point $(0\,;3)$ se trouve :

Réponse : Son abscisse est nulle.

5Le point $(-2\,;0)$ se trouve :

Réponse : Son ordonnée est nulle.

6Le milieu du segment $[AB]$ avec $A(1\,;2)$ et $B(5\,;4)$ a pour coordonnées :

Réponse : On fait la moyenne des abscisses et des ordonnées.

7La distance $AB$ avec $A(1\,;1)$ et $B(4\,;5)$ vaut :

Réponse : $AB=\sqrt{3^{2}+4^{2}}=5$.

8Les coordonnées du vecteur $\overrightarrow{AB}$ avec $A(1\,;2)$ et $B(4\,;6)$ sont :

Réponse : $\overrightarrow{AB}=\left(x_{B}-x_{A}\,;y_{B}-y_{A}\right)$.

9Un repère orthonormé a :

Réponse : C'est la condition pour que les distances se calculent avec la formule habituelle.

10Le symétrique de $A(3\,;2)$ par rapport à l'origine est :

Réponse : On change les deux signes.

11Le symétrique de $A(3\,;2)$ par rapport à l'axe des abscisses est :

Réponse : On change le signe de l'ordonnée.

12Les points $(2\,;3)$ et $(3\,;2)$ :

Réponse : Les coordonnées ne sont pas dans le même ordre.

13La norme du vecteur $(3\,;4)$ vaut :

Réponse : $\sqrt{3^{2}+4^{2}}=5$.

14Le milieu de $[AB]$ avec $A(0\,;0)$ et $B(6\,;2)$ a pour coordonnées :

Réponse : $\left(\dfrac{0+6}{2}\,;\dfrac{0+2}{2}\right)=(3\,;1)$.

15Le point $A(-1\,;2)$ se situe dans :

Réponse : Abscisse négative et ordonnée positive.

16La distance entre $O(0\,;0)$ et $M(3\,;4)$ vaut :

Réponse : $OM=\sqrt{3^{2}+4^{2}}=5$.

17Deux points qui ont la même ordonnée sont sur :

Réponse : Leur différence d'ordonnée est nulle.

18La formule de la distance $AB$ est :

Réponse : C'est le théorème de Pythagore dans le repère orthonormé.

19Les coordonnées du vecteur $\overrightarrow{AB}$ sont :

Réponse : On soustrait les coordonnées de départ à celles d'arrivée.

20Le point $(1\,;1)$ se trouve dans :

Réponse : Les deux coordonnées sont positives.
