Quiz — Nombres complexes et géométrie

Maths expertes · chapitre 5 · 20 questions

1Le point $M$ d'affixe $z=a+ib$ a pour coordonnées :

Réponse : Abscisse : partie réelle, ordonnée : partie imaginaire.

2$|z_B-z_A|$ représente :

Réponse : Module de l'affixe du vecteur.

3L'ensemble des points $M$ tels que $|z-z_A|=r$ est :

Réponse : Équation d'un cercle.

4L'ensemble des points $M$ tels que $|z-z_A|=|z-z_B|$ est :

Réponse : Points équidistants de $A$ et $B$.

5L'affixe du milieu de $[AB]$ est :

Réponse : Moyenne des affixes.

6$\arg(z_B-z_A)$ représente :

Réponse : Argument du vecteur $\vect{AB}$.

7Trois points $A$, $B$, $C$ sont alignés si :

Réponse : Argument nul ou $\pi$.

8Le triangle $ABC$ est rectangle en $A$ si :

Réponse : Angle droit : argument $\pm\dfrac{\pi}{2}$.

9Le triangle $ABC$ est équilatéral si :

Réponse : Trois côtés égaux.

10La rotation de centre $\Omega$ d'affixe $\omega$ et d'angle $\theta$ associe à $z$ :

Réponse : Forme complexe de la rotation.

11La translation de vecteur d'affixe $b$ associe à $z$ :

Réponse : Translation.

12L'homothétie de centre $\Omega$ et de rapport $k$ associe à $z$ :

Réponse : Forme complexe.

13L'ensemble des points $M$ tels que $\arg(z-z_A)=\dfrac{\pi}{4}$ est :

Réponse : Demi-droite d'origine $A$.

14$|z-1|=|z+i|$ est la médiatrice de $[AB]$ avec :

Réponse : Centres $1$ et $-i$.

15Le cercle de centre $A$ et de rayon $3$ a pour équation :

Réponse : Module constant.

16Si $M$ et $M'$ ont pour affixes $z$ et $-\bar z$, la transformation est :

Réponse : Composition symétrie / axe.

17$|z+2i|$ est la distance de $M$ au point d'affixe :

Réponse : $|z-(-2i)|$.

18Un argument de $z-1$ permet d'étudier :

Réponse : Angle orienté.

19L'écriture complexe d'une similitude directe est :

Réponse : Similitude directe.

20Le centre d'une similitude $z\mapsto az+b$ ($a\neq1$) est :

Réponse : On résout $\omega=a\omega+b$.
