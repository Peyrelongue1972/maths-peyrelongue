1Pour tout réel $a>0$, $a^{0}$ vaut :

Réponse : Toute puissance nulle vaut $1$.

2Pour tout réel $a>0$, $a^{1}$ vaut :

Réponse : $a^{1}=a$.

3Pour $a>0$, $a^{x}\times a^{y}$ vaut :

Réponse : On additionne les exposants.

4Pour $a>0$, $\dfrac{a^{x}}{a^{y}}$ vaut :

Réponse : On soustrait les exposants.

5Pour $a>0$, $\left(a^{x}\right)^{y}$ vaut :

Réponse : On multiplie les exposants.

6$2^{3}$ vaut :

Réponse : $2^{3}=2\times2\times2=8$.

7$2^{-2}$ vaut :

Réponse : $2^{-2}=\dfrac{1}{2^{2}}=0{,}25$.

8Pour $a>1$, la fonction $x\mapsto a^{x}$ est :

Réponse : Une base supérieure à $1$ donne une croissance.

9Pour $0

Réponse : Une base comprise entre $0$ et $1$ donne une décroissance.

10Pour tout $a>0$ et tout réel $x$, $a^{x}$ est :

Réponse : Une exponentielle de base $a$ est toujours positive.

11Une grandeur augmente de $3\,\%$ par an. Le coefficient multiplicateur annuel est :

Réponse : $1+0{,}03=1{,}03$.

12$1{,}05^{2}$ vaut environ :

Réponse : $1{,}05^{2}=1{,}1025$, soit $+10{,}25\,\%$.

13Une hausse de $10\,\%$ par an pendant $3$ ans correspond à un coefficient global de :

Réponse : On multiplie les coefficients annuels.

14$4^{\frac{1}{2}}$ vaut :

Réponse : $4^{\frac12}=\sqrt{4}=2$.

15$3^{-1}$ vaut :

Réponse : $3^{-1}=\dfrac{1}{3}$.

16$5^{0}+5^{1}$ vaut :

Réponse : $1+5=6$.

17Une population diminue de $20\,\%$ par an. Le coefficient annuel est :

Réponse : $1-0{,}20=0{,}8$.

Réponse : La fonction est décroissante et positive : elle tend vers $0$.

Réponse : $0{,}9\times0{,}9\times0{,}9=0{,}729$.

Réponse : On multiplie par $1{,}04$ chaque année.
