Quiz — Nombres complexes : applications

Maths expertes · chapitre 3 · 20 questions

Score : 0 / 20

1La forme trigonométrique de $z$ s'écrit :

Réponse : Avec $r=|z|$ et $\theta=\arg z$.

2Le module de $z^{n}$ vaut :

Réponse : Le module est multiplicatif.

3$\arg\left(z^{n}\right)$ vaut :

Réponse : Formule de Moivre.

4Formule de Moivre : $(\cos\theta+i\sin\theta)^{n}$ vaut :

Réponse : Moivre.

5$\left(\dfrac{1+i}{\sqrt2}\right)^{4}$ vaut :

Réponse : $\dfrac{1+i}{\sqrt2}=e^{i\pi/4}$, donc la puissance $4$ vaut $e^{i\pi}=-1$.

6Les racines $n$-ièmes de l'unité sont :

Réponse : $n$ racines régulièrement réparties.

7Les racines cubiques de $1$ sont :

Réponse : Avec $j=e^{2i\pi/3}$ et $1+j+j^{2}=0$.

8L'équation $z^{3}=8$ a pour solutions :

Réponse : On multiplie la racine réelle par les racines cubiques de l'unité.

9Pour résoudre $z^{n}=a$, on écrit :

Réponse : Puis on répartit les arguments.

10Une équation polynomiale de degré $n$ a, dans $\C$ :

Réponse : Théorème de d'Alembert-Gauss.

11Les solutions de $z^{2}=1+i$ ont pour module :

Réponse : $|1+i|=\sqrt2$ et $|z|^{2}=\sqrt2$, donc $|z|=\sqrt[4]{2}$.

12$e^{i\theta}+e^{-i\theta}$ vaut :

Réponse : Formules d'Euler.

13$e^{i\theta}-e^{-i\theta}$ vaut :

Réponse : Formules d'Euler.

14$\cos\theta$ s'écrit :

Réponse : Euler.

15Linéariser $\cos^{2}\theta$ donne :

Réponse : Formule de duplication.

16$(1+i)^{2}$ vaut :

Réponse : $1+2i+i^{2}=2i$.

17Un argument de $-1+i$ est :

Réponse : $|{-1+i}|=\sqrt2$ et le point est dans le deuxième quadrant.

18$z\bar z$ pour $z=2+3i$ vaut :

Réponse : $4+9=13$.

19Le quotient $\dfrac{z_1}{z_2}$ a pour module :

Réponse : Le module est compatible avec le quotient.

20Si $z=e^{i\theta}$, alors $\bar z$ vaut :

Réponse : Conjugaison : l'argument change de signe.
