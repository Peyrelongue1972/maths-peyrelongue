Quiz — Équations différentielles

Terminale spécialité · chapitre 8 · 20 questions

Score : 0 / 20

1Une équation différentielle est une équation qui relie :

Réponse : C'est la définition.

2Les solutions de l'équation $y'=0$ sur $\mathbb{R}$ sont :

Réponse : Une dérivée nulle caractérise une fonction constante.

3Les solutions de l'équation $y'=ay$ (avec $a$ réel) sont :

Réponse : Ce sont les fonctions exponentielles de paramètre $a$.

4Les solutions de $y'=2y$ sont :

Réponse : $a=2$ dans la formule générale.

5La solution de $y'=y$ telle que $y(0)=3$ est :

Réponse : $y(x)=C\mathrm{e}^{x}$ et $y(0)=C=3$.

6Les solutions de $y'+2y=0$ sont :

Réponse : On écrit $y'=-2y$.

7La solution de $y'=3y$ telle que $y(0)=1$ est :

Réponse : $y(x)=C\mathrm{e}^{3x}$ avec $C=1$.

8Une condition initiale permet de :

Réponse : C'est la donnée de $y(x_0)$.

9Les solutions de $y'=2y+1$ comportent une solution particulière constante égale à :

Réponse : Si $y$ est constante, $0=2y+1$, donc $y=-\dfrac{1}{2}$.

10La solution de $y'=0$ avec $y(0)=5$ est :

Réponse : Les solutions sont constantes et valent $5$.

11Les solutions de $y'=-y$ sont :

Réponse : $a=-1$ dans la formule générale.

12Les solutions de $y'=0{,}5y$ sont :

Réponse : $a=0{,}5$.

13La solution de $y'=y$ avec $y(0)=0$ est :

Réponse : $C=0$ : la solution est identiquement nulle.

14Pour vérifier qu'une fonction est solution d'une équation différentielle, on :

Réponse : On vérifie l'égalité pour tout $x$.

15Les solutions de $y''=0$ sur $\mathbb{R}$ sont :

Réponse : $y'=C$ puis $y=Cx+D$.

16Combien de solutions l'équation $y'=2y$ avec $y(0)=1$ admet-elle ?

Réponse : La condition initiale fixe la constante.

17Pour l'équation $y'=ay$ avec $a<0$, le sens de variation d'une solution :

Réponse : Les solutions s'écrivent $y(x)=C\mathrm{e}^{ax}$. Si $C>0$, la fonction est décroissante (elle tend vers $0$) ; si $C<0$, elle est croissante (elle part d'un nombre négatif et tend vers $0$). Par exemple $y(0)=-1$ donne $y(x)=-\mathrm{e}^{ax}$, qui est croissante.

18La solution générale de $y'=4y$ est :

Réponse : Forme $C\mathrm{e}^{ax}$ avec $a=4$.

19La solution de $y'=y$ telle que $y(1)=0$ est :

Réponse : $C\mathrm{e}^{1}=0$ donne $C=0$.

20L'équation $y'=y$ signifie que :

Réponse : C'est la propriété caractéristique de l'exponentielle.
