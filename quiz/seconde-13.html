Quiz — Les fonctions de référence

Seconde · chapitre 13 · 20 questions

Score : 0 / 20

1La fonction inverse $f(x)=\dfrac{1}{x}$ est définie sur :

Réponse : Le dénominateur ne doit pas être nul.

2La fonction racine carrée $f(x)=\sqrt{x}$ est définie sur :

Réponse : Une racine carrée exige un nombre positif ou nul.

3On a $f(x)=\dfrac{1}{x}$. Alors $f(2)$ vaut :

Réponse : $f(2)=\dfrac{1}{2}$.

4$\sqrt{4}$ est égal à :

Réponse : $2^{2}=4$, donc $\sqrt{4}=2$.

5On a $f(x)=x^{3}$. Alors $f(-2)$ vaut :

Réponse : $(-2)^{3}=-8$.

6Sur $]0\,;+\infty[$, la fonction inverse est :

Réponse : Quand $x$ augmente, $\dfrac{1}{x}$ diminue.

7Sur $[0\,;+\infty[$, la fonction racine carrée est :

Réponse : Quand $x$ augmente, $\sqrt{x}$ augmente.

8La fonction cube $f(x)=x^{3}$ est sur $\mathbb{R}$ :

Réponse : Elle croît sur tout $\mathbb{R}$.

9On a $f(x)=\dfrac{1}{x}$. Alors $f(-1)$ vaut :

Réponse : $f(-1)=-1$.

10La courbe de la fonction inverse est :

Réponse : She est composée de deux branches.

11La courbe de la fonction racine carrée :

Réponse : $f(0)=0$ et la courbe est définie pour $x\geqslant0$.

12La courbe de la fonction cube est symétrique par rapport à :

Réponse : $f(-x)=-f(x)$ : on parle de symétrie centrale.

13$\sqrt{9}$ est égal à :

Réponse : $3^{2}=9$.

14La fonction inverse peut-elle s'annuler ?

Réponse : $\dfrac{1}{x}\neq0$ pour tout $x\neq0$.

15Pour tout $x\geqslant0$, $\sqrt{x}$ est :

Réponse : Une racine carrée est toujours positive ou nulle.

16Sur l'intervalle $[0\,;1]$, on a :

Réponse : Multiplier par $x$ (entre $0$ et $1$) diminue le nombre.

17Pour $x>0$, $\dfrac{1}{x}$ est :

Réponse : Le quotient de deux nombres positifs est positif.

18La courbe de la fonction inverse coupe-t-elle l'axe des abscisses ?

Réponse : La fonction ne s'annule jamais.

19Pour $x>1$, on a :

Réponse : Multiplier par $x$ (supérieur à $1$) augmente le nombre.

20On a $f(x)=\sqrt{x}$. Alors $f(0)$ vaut :

Réponse : $\sqrt{0}=0$.
