1Une loi de probabilité continue est donnée par :

Réponse : $P(a\leqslant X\leqslant b)=\int_a^b f$.

2Une densité $f$ vérifie :

Réponse : Conditions d'une densité.

3Pour une loi continue, $P(X=a)$ vaut :

Réponse : Un point a une probabilité nulle.

4$P(a\leqslant X\leqslant b)$ se calcule par :

Réponse : On intègre la densité sur l'intervalle.

5L'espérance d'une loi continue de densité $f$ sur $[a\,;b]$ est :

Réponse : Moyenne pondérée par la densité.

6La loi uniforme sur $[a\,;b]$ a pour densité :

Réponse : Densité constante.

7Pour la loi uniforme sur $[0\,;1]$, $P\left(X\leqslant0{,}3\right)$ vaut :

Réponse : La probabilité est proportionnelle à la longueur.

8La loi exponentielle de paramètre $\lambda$ a pour densité :

Réponse : Modélise des durées de vie sans mémoire.

9Pour une loi exponentielle de paramètre $\lambda$, $E(X)$ vaut :

Réponse : Espérance = $1/\lambda$.

10La loi exponentielle est dite :

Réponse : $P(X>s+t\mid X>s)=P(X>t)$.

11La loi normale est caractérisée par :

Réponse : Espérance et écart-type.

12La courbe de la loi normale est :

Réponse : Courbe de Gauss.

13Pour $X\sim\mathcal{N}(0\,;1)$, $P(-1\leqslant X\leqslant1)\approx$ :

Réponse : Règle des $68\,\%$.

14Pour $X\sim\mathcal{N}(0\,;1)$, $P(-2\leqslant X\leqslant2)\approx$ :

Réponse : Règle des $95\,\%$.

15Pour $X\sim\mathcal{N}(0\,;1)$, $P(X\leqslant0)$ vaut :

Réponse : Symétrie autour de $0$.

16Si $X\sim\mathcal{N}(\mu\,;\sigma^{2})$, alors $\dfrac{X-\mu}{\sigma}$ suit :

Réponse : Centrage et réduction.

17La loi normale est une loi :

Réponse : Densité en cloche.

18$P(X\geqslant1)$ pour $X\sim\mathcal{N}(0\,;1)$ vaut :

Réponse : On utilise l'événement contraire.

19Une loi binomiale peut être approchée par une loi normale lorsque :

Réponse : Théorème de Moivre-Laplace.

20L'écart-type d'une loi normale mesure :

Réponse : Plus $\sigma$ est grand, plus la cloche est large.
