Quiz — Variables aléatoires

Terminale STMG · chapitre 7 · 20 questions

Score : 0 / 20

1Une variable aléatoire $X$ associe :

Réponse : C'est une fonction définie sur l'univers.

2Dans une loi de probabilité, la somme des probabilités vaut :

Réponse : Les valeurs possibles forment une partition de l'univers.

3L'espérance $E(X)$ se calcule par :

Réponse : C'est la moyenne pondérée des valeurs.

4Si $X$ est constante égale à $5$, alors $E(X)$ vaut :

Réponse : L'espérance d'une constante est cette constante.

5Un jeu est équitable lorsque :

Réponse : Aucun des deux joueurs n'est avantagé en moyenne.

6On lance un dé équilibré à six faces. L'espérance du numéro obtenu vaut :

Réponse : $\dfrac{1+2+3+4+5+6}{6}=3{,}5$.

7$X$ prend les valeurs $0$ et $10$ avec $P(X=10)=0{,}1$. Alors $E(X)$ vaut :

Réponse : $E(X)=0\times0{,}9+10\times0{,}1=1$.

8La variance d'une variable aléatoire mesure :

Réponse : Elle quantifie l'étalement des valeurs.

9Pour une variable aléatoire $X$, la variance $V(X)$ est :

Réponse : C'est une moyenne de carrés.

10Pour tous réels $a$ et $b$, $E(aX+b)$ vaut :

Réponse : L'espérance est linéaire.

11L'écart type $\sigma(X)$ est égal à :

Réponse : L'écart type est la racine carrée de la variance.

12$E(2X+3)$ vaut :

Réponse : Linéarité de l'espérance.

13$X$ prend les valeurs $1$ et $2$ avec la même probabilité $0{,}5$. Alors $E(X)$ vaut :

Réponse : $1\times0{,}5+2\times0{,}5=1{,}5$.

14L'espérance d'une variable aléatoire :

Réponse : Pour un dé, $E(X)=3{,}5$ alors que $X$ ne prend que des entiers.

15Le gain algébrique d'un jeu se calcule en :

Réponse : Gain algébrique $=$ gain $-$ mise.

16Un jeu est favorable au joueur lorsque :

Réponse : Le gain moyen est positif.

17Si toutes les valeurs prises par $X$ sont égales, alors $V(X)$ vaut :

Réponse : Aucune dispersion : tous les écarts à la moyenne sont nuls.

18Dans une loi de probabilité, chaque probabilité $p_{i}$ est :

Réponse : Une probabilité est comprise entre $0$ et $1$.

19L'espérance s'interprète comme :

Réponse : La moyenne se stabilise autour de $E(X)$.

20Pour tout réel $a$, $V(aX)$ vaut :

Réponse : Multiplier les valeurs par $a$ multiplie les carrés des écarts par $a^{2}$.
