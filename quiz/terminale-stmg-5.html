Quiz — Fonction exponentielle

Terminale STMG · chapitre 5 · 20 questions

Score : 0 / 20

1Le nombre $\mathrm{e}$ vaut environ :

Réponse : $\mathrm{e}\approx2{,}718$ est la base de l'exponentielle.

2$\mathrm{e}^{0}$ vaut :

Réponse : Toute puissance nulle vaut $1$.

3Pour tous réels $x$ et $y$, $\mathrm{e}^{x+y}$ vaut :

Réponse : L'exponentielle transforme les sommes en produits.

4La dérivée de $\mathrm{e}^{x}$ est :

Réponse : L'exponentielle est sa propre dérivée.

5Pour tout réel $x$, $\mathrm{e}^{x}$ est :

Réponse : Une exponentielle est toujours strictement positive.

6Sur $\mathbb{R}$, la fonction exponentielle est :

Réponse : Sa dérivée $\mathrm{e}^{x}$ est positive.

7Pour tout réel $x$, $\ln\left(\mathrm{e}^{x}\right)$ vaut :

Réponse : $\ln$ et $\exp$ sont réciproques.

8Pour tout réel $x>0$, $\mathrm{e}^{\ln(x)}$ vaut :

Réponse : Ce sont deux fonctions réciproques.

9Pour tout réel $x$, $\mathrm{e}^{-x}$ vaut :

Réponse : $a^{-x}=\dfrac{1}{a^{x}}$.

10La dérivée de $\mathrm{e}^{2x}$ est :

Réponse : On dérive la composée.

11$\mathrm{e}^{\ln(2)}$ vaut :

Réponse : $\mathrm{e}^{\ln 2}=2$.

12$\ln\left(\mathrm{e}\right)$ vaut :

Réponse : $\ln(\mathrm{e})=1$.

13Quand $x$ tend vers $-\infty$, $\mathrm{e}^{x}$ tend vers :

Réponse : La courbe admet l'axe des abscisses comme asymptote.

14Si $\mathrm{e}^{x}=\mathrm{e}^{y}$, alors :

Réponse : L'exponentielle est strictement croissante.

15L'équation $\mathrm{e}^{x}=3$ a pour solution :

Réponse : On applique le logarithme.

16$\mathrm{e}^{2\ln(3)}$ vaut :

Réponse : $2\ln3=\ln\left(3^{2}\right)=\ln9$.

17La fonction exponentielle peut-elle s'annuler ?

Réponse : $\mathrm{e}^{x}>0$ pour tout $x$.

18Pour tout réel $x$ et tout entier $n$ :

Réponse : On multiplie les exposants.

19Une quantité décroît de $5\,\%$ par an. Le facteur annuel est $\mathrm{e}^{k}$ avec :

Réponse : On cherche $k$ tel que $\mathrm{e}^{k}=0{,}95$.

20L'équation $\mathrm{e}^{x}=1$ a pour solution :

Réponse : $\mathrm{e}^{0}=1$.
