Quiz — Les suites numériques

Première STMG · chapitre 1 · 20 questions

Score : 0 / 20

1Une suite numérique $(u_{n})$ est une fonction définie sur :

Réponse : Les termes sont numérotés par des entiers $0$, $1$, $2$…

2On a $u_{n}=3n-1$. Alors $u_{5}$ vaut :

Réponse : $u_{5}=3\times5-1=14$.

3On a $u_{0}=2$ et $u_{n+1}=u_{n}+3$. Alors $u_{3}$ vaut :

Réponse : $u_{1}=5$, $u_{2}=8$, $u_{3}=11$.

4La suite définie sur $\mathbb{N}^{*}$ par $u_{n}=\dfrac{1}{n}$ est :

Réponse : Les termes diminuent : $1$, $0{,}5$, $0{,}33$…

5La suite définie par $u_{n}=n^{2}$ est :

Réponse : $0$, $1$, $4$, $9$, $16$… : elle croît.

6La suite définie par $u_{n}=(-1)^{n}$ est :

Réponse : Ses termes alternent entre $1$ et $-1$.

7On a $u_{0}=5$ et $u_{n+1}=2u_{n}$. Alors $u_{3}$ vaut :

Réponse : $u_{1}=10$, $u_{2}=20$, $u_{3}=40$.

8La représentation graphique d'une suite est :

Réponse : On place les points $(n\,;u_{n})$, non reliés entre eux.

9On a $u_{n}=4n+1$. Alors $u_{0}$ vaut :

Réponse : $u_{0}=4\times0+1=1$.

10Si $u_{n+1}-u_{n}<0$ pour tout $n$, la suite est :

Réponse : Chaque terme est inférieur au précédent.

11On a $u_{n}=2n-5$. Alors $u_{2}$ vaut :

Réponse : $u_{2}=2\times2-5=-1$.

12La suite définie par $u_{n}=3$ pour tout $n$ est :

Réponse : Tous ses termes valent $3$.

13Dire qu'une suite est majorée signifie que :

Réponse : Il existe un réel $M$ tel que $u_{n}\leqslant M$ pour tout $n$.

14La suite définie par $u_{n}=\dfrac{1}{2^{n}}$ est :

Réponse : Chaque terme est la moitié du précédent.

15Une suite définie par une formule $u_{n}=f(n)$ est dite définie :

Réponse : On calcule $u_{n}$ directement à partir de $n$.

16Pour une suite définie sur $\mathbb{N}^{*}$, le premier terme est :

Réponse : $\mathbb{N}^{*}$ commence à $1$.

17On a $u_{n}=10-2n$. Cette suite est :

Réponse : $u_{n+1}-u_{n}=-2<0$.

18On a $u_{0}=1$ et $u_{n+1}=3u_{n}$. Alors $u_{2}$ vaut :

Réponse : $u_{1}=3$ puis $u_{2}=9$.

19Une suite est bornée lorsque :

Réponse : Il existe $m$ et $M$ tels que $m\leqslant u_{n}\leqslant M$.

20On a $u_{n}=5n^{2}$. Alors $u_{2}$ vaut :

Réponse : $u_{2}=5\times2^{2}=20$.
