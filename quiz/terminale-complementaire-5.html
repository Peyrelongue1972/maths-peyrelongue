Quiz — Logarithme népérien

Terminale complémentaire · chapitre 5 · 20 questions

Score : 0 / 20

1$\ln 1$ vaut :

Réponse : $\ln1=0$ car $\mathrm{e}^{0}=1$.

2$\ln\mathrm{e}$ vaut :

Réponse : $\ln\mathrm{e}=1$.

3Le domaine de définition de $\ln$ est :

Réponse : $\ln x$ n'existe que pour $x>0$.

4$\ln(ab)$ vaut :

Réponse : Propriété fondamentale du logarithme (pour $a,b>0$).

5$\ln\left(\dfrac{a}{b}\right)$ vaut :

Réponse : $\ln\frac ab=\ln a-\ln b$.

6$\ln\left(a^{n}\right)$ vaut :

Réponse : $\ln(a^{n})=n\ln a$.

7$\ln\left(\sqrt{2}\right)$ vaut :

Réponse : $\sqrt2=2^{1/2}$, donc $\ln\sqrt2=\frac12\ln2$.

8La fonction $\ln$ est :

Réponse : $(\ln x)'=\dfrac1x>0$.

9$\lim\limits_{x\to0^{+}}\ln x$ est :

Réponse : L'axe des ordonnées est asymptote verticale.

10$\lim\limits_{x\to+\infty}\ln x$ est :

Réponse : Le logarithme croît lentement mais tend vers $+\infty$.

11$\ln\left(\mathrm{e}^{3}\right)$ vaut :

Réponse : $\ln(\mathrm{e}^{x})=x$.

12$\mathrm{e}^{\ln 5}$ vaut :

Réponse : $\mathrm{e}^{\ln x}=x$ pour $x>0$.

13L'équation $\ln x=2$ a pour solution :

Réponse : $x=\mathrm{e}^{2}$.

14L'équation $\mathrm{e}^{x}=7$ a pour solution :

Réponse : On applique $\ln$ : $x=\ln7$.

15La dérivée de $\ln x$ est :

Réponse : Pour $x>0$.

16La dérivée de $x\mapsto\ln(2x)$ est :

Réponse : $\ln(2x)=\ln2+\ln x$, donc la dérivée est $\dfrac1x$.

17$\ln 2+\ln 3$ vaut :

Réponse : $\ln a+\ln b=\ln(ab)$.

18$\ln\left(2\mathrm{e}^{2}\right)$ vaut :

Réponse : $\ln2+\ln(\mathrm{e}^{2})=\ln2+2$.

19$\lim\limits_{x\to+\infty}\dfrac{\ln x}{x}$ est :

Réponse : Croissances comparées.

20Pour tout $x>0$, $\ln x\leqslant x-1$, avec égalité seulement en :

Réponse : C'est la concavité du logarithme (tangente en $1$).
