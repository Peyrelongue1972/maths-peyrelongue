1La dérivée de $\sin(x)$ est :

Réponse : La dérivée du sinus est le cosinus.

2La dérivée de $\cos(x)$ est :

Réponse : La dérivée du cosinus est l'opposé du sinus.

3La période de la fonction sinus est :

Réponse : $\sin(x+2\pi)=\sin(x)$.

4La fonction sinus est :

Réponse : $\sin(-x)=-\sin(x)$.

5La fonction cosinus est :

Réponse : $\cos(-x)=\cos(x)$.

6La dérivée de $\sin(2x)$ est :

Réponse : On compose avec $u(x)=2x$.

7La dérivée de $\cos(3x)$ est :

Réponse : $\left(\cos u\right)'=-u'\sin u$.

8$\lim\limits_{x\to0}\dfrac{\sin(x)}{x}$ vaut :

Réponse : C'est une limite de référence.

9Le maximum de la fonction sinus sur $\mathbb{R}$ est :

Réponse : $-1\leqslant\sin(x)\leqslant1$.

10Pour tout réel $x$, $\cos(x+\pi)$ vaut :

Réponse : Les points sont symétriques par rapport à l'origine.

11La dérivée de $x\sin(x)$ est :

Réponse : Formule du produit.

12L'équation $\sin(x)=0$ a pour solutions :

Réponse : Le sinus s'annule tous les $\pi$.

13La dérivée de $\cos^{2}(x)$ est :

Réponse : $\left(u^{2}\right)'=2uu'$ avec $u=\cos x$.

14Sur $[0\,;2\pi]$, la fonction sinus atteint son maximum en :

Réponse : $\sin\left(\dfrac{\pi}{2}\right)=1$.

15Sur $[0\,;\pi]$, la fonction cosinus est :

Réponse : Elle décroît de $1$ à $-1$.

16$\sin\left(\dfrac{\pi}{6}\right)$ vaut :

Réponse : Valeur remarquable du sinus.

17La dérivée seconde de $\sin(x)$ est :

Réponse : $\left(\sin\right)'=\cos$ puis $\left(\cos\right)'=-\sin$.

18La courbe de la fonction sinus est appelée :

Réponse : C'est la courbe de la fonction sinus.

19Sur l'intervalle $\left[-\dfrac{\pi}{2}\,;\dfrac{\pi}{2}\right]$, le cosinus est :

Réponse : Le cosinus est positif sur cet intervalle centré en $0$.

20La dérivée de $\sin(x)+\cos(x)$ est :

Réponse : On dérive terme à terme.
