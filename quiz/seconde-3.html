Quiz — Généralités sur les fonctions

Seconde · chapitre 3 · 20 questions

Score : 0 / 20

1On a $f(x)=2x+1$. L'image de $3$ par $f$ est :

Réponse : $f(3)=2\times3+1=7$.

2On a $f(x)=x+2$. Un antécédent de $5$ par $f$ est :

Réponse : On résout $x+2=5$, soit $x=3$.

3On a $f(x)=x^{2}$. Alors $f(-2)$ vaut :

Réponse : $(-2)^{2}=4$.

4L'ensemble de définition de $f(x)=\dfrac{1}{x}$ est :

Réponse : Le dénominateur doit être non nul.

5L'ensemble de définition de $f(x)=\sqrt{x}$ est :

Réponse : Une racine carrée exige un nombre positif ou nul.

6On a $f(x)=3x-6$. Alors $f(0)$ vaut :

Réponse : $f(0)=3\times0-6=-6$.

7Les antécédents de $9$ par $f(x)=x^{2}$ sont :

Réponse : $x^{2}=9$ donne $x=3$ ou $x=-3$.

8Sur $]-\infty\,;0]$, la fonction $f(x)=x^{2}$ est :

Réponse : Sur les nombres négatifs, le carré diminue quand $x$ augmente vers $0$.

9Le minimum de $f(x)=x^{2}+1$ sur $\mathbb{R}$ vaut :

Réponse : $x^{2}\geqslant0$, donc $f(x)\geqslant1$.

10Une fonction $f$ est croissante sur un intervalle $I$ lorsque :

Réponse : La croissance conserve l'ordre.

11La fonction $f(x)=-2x+5$ est sur $\mathbb{R}$ :

Réponse : Son coefficient directeur $-2$ est négatif.

12Le point $(2\,;5)$ appartient à la courbe de $f$ si et seulement si :

Réponse : Un point est sur la courbe si ses coordonnées vérifient la relation.

13On a $f(x)=x^{2}-3$. Alors $f(2)$ vaut :

Réponse : $f(2)=4-3=1$.

14La solution de $4x-8=0$ est :

Réponse : $4x=8$, donc $x=2$.

15Le minimum de $f(x)=x^{2}$ est atteint :

Réponse : $f(0)=0$ et $f(x)\geqslant0$.

16La courbe d'une fonction coupe l'axe des ordonnées au point :

Réponse : L'axe des ordonnées correspond à $x=0$.

17Un antécédent de $0$ par $f(x)=x^{2}$ est :

Réponse : $f(0)=0$.

18On a $f(x)=2x^{2}-1$. Alors $f(1)$ vaut :

Réponse : $f(1)=2-1=1$.

19On a $f(x)=\dfrac{1}{x}$. Alors $f(2)$ vaut :

Réponse : $f(2)=\dfrac{1}{2}=0{,}5$.

20Graphiquement, les solutions de $f(x)=k$ sont :

Réponse : On cherche les $x$ tels que la hauteur vaille $k$.
