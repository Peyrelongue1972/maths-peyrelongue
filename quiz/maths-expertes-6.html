Réponse : Définition.

2Le plus petit nombre premier est :

Réponse : $1$ n'est pas premier.

Réponse : Théorème d'Euclide.

4Tout entier $n\geqslant2$ :

Réponse : Théorème fondamental de l'arithmétique.

5La décomposition de $360$ en facteurs premiers est :

Réponse : $360=8\times9\times5$.

6Le test de primalité consiste à tester les diviseurs jusqu'à :

Réponse : Au-delà, les diviseurs se répètent.

7$2^{p}-1$ est premier si :

Réponse : Nombres de Mersenne : condition nécessaire, non suffisante.

8Le PGCD de $a=p^{2}q$ et $b=pq^{3}$ est :

Réponse : On prend les exposants minimaux.

9Le PPCM de $12$ et $18$ est :

Réponse : $2^{2}\times3^{2}=36$.

10On a $\mathrm{PGCD}(a\,;b)\times\mathrm{PPCM}(a\,;b)=$ :

Réponse : Relation PGCD-PPCM.

11Si $p$ est premier et $p\mid ab$, alors :

Réponse : Lemme d'Euclide.

12Le nombre de diviseurs de $2^{3}\times3^{2}$ est :

Réponse : $(3+1)(2+1)=12$.

13$641$ divise $2^{32}+1$ :

Réponse : Contre-exemple historique à Fermat.

14Le crible d'Ératosthène permet de :

Réponse : On élimine les multiples.

15$\sqrt{100}$ est premier ?

Réponse : Test jusqu'à $\sqrt n=10$.

16Si $n$ n'est divisible par aucun premier $\leqslant\sqrt n$, alors :

Réponse : Critère de primalité.

17$2^{11}-1=2047=23\times89$ :

Réponse : Contre-exemple aux nombres de Mersenne.

18La valuation $v_p(n)$ est :

Réponse : Exposant dans la factorisation.

19Deux entiers consécutifs sont :

Réponse : $\mathrm{PGCD}(n\,;n+1)=1$.

Réponse : Un contre-exemple suffit.
