Quiz — Les vecteurs

Seconde · chapitre 4 · 20 questions

Score : 0 / 20

1Deux vecteurs sont égaux lorsqu'ils ont :

Réponse : C'est la définition de l'égalité de deux vecteurs.

2$\overrightarrow{AB}=\overrightarrow{DC}$ équivaut à dire que $ABCD$ est :

Réponse : C'est la caractérisation d'un parallélogramme par les vecteurs.

3La relation de Chasles s'écrit :

Réponse : Le point intermédiaire disparaît.

4Pour tous points $A$, $B$, $C$, on a :

Réponse : C'est la relation de Chasles.

5La norme du vecteur nul est :

Réponse : Le vecteur nul $\vec{0}$ a une longueur nulle.

6Le vecteur opposé de $\overrightarrow{AB}$ est :

Réponse : Même direction, même norme, sens contraire.

7Le vecteur $2\vec{u}$ a pour norme :

Réponse : Multiplier un vecteur par $2$ double sa longueur.

8Le vecteur $-\vec{u}$ est :

Réponse : Le signe change le sens.

9Dire que $I$ est le milieu de $[AB]$ équivaut à :

Réponse : Le milieu est équidistant et aligné.

10La somme de deux vecteurs se construit :

Réponse : On place les vecteurs bout à bout ou on utilise le parallélogramme.

11$\overrightarrow{AB}+\overrightarrow{BA}$ est égal à :

Réponse : Ce sont deux vecteurs opposés.

12La norme de $\vec{u}+\vec{v}$ est en général :

Réponse : Il n'y a égalité que si les vecteurs ont le même sens.

13Pour tous vecteurs $\vec{u}$ et $\vec{v}$, on a :

Réponse : L'addition des vecteurs est commutative.

14$3\vec{u}-2\vec{u}$ est égal à :

Réponse : On combine les coefficients : $3-2=1$.

15Deux vecteurs sont colinéaires lorsqu'ils ont :

Réponse : Colinéaire signifie porté par des droites parallèles.

16Si $\overrightarrow{AB}=\overrightarrow{BC}$, alors :

Réponse : Les deux vecteurs égaux se suivent : $B$ est au milieu.

17Le vecteur $\overrightarrow{AA}$ est :

Réponse : Un vecteur dont les extrémités sont confondues est nul.

18Pour tout réel $k$ et tous vecteurs, on a :

Réponse : C'est la distributivité de la multiplication par un réel.

19$-(\vec{u}+\vec{v})$ est égal à :

Réponse : L'opposé d'une somme est la somme des opposés.

20Deux vecteurs non nuls $\vec{u}$ et $\vec{v}$ sont colinéaires si et seulement si :

Réponse : C'est la caractérisation par un coefficient de proportionnalité.
