Quiz — Fonction exponentielle

Première spécialité · chapitre 9 · 20 questions

Score : 0 / 20

1$\mathrm{e}^{0}$ vaut :

Réponse : Par convention, $\mathrm{e}^{0}=1$.

2Pour tous réels $a$ et $b$, $\mathrm{e}^{a}\times\mathrm{e}^{b}$ est égal à :

Réponse : On additionne les exposants.

3Pour tous réels $a$ et $b$, $\dfrac{\mathrm{e}^{a}}{\mathrm{e}^{b}}$ est égal à :

Réponse : On soustrait les exposants.

4Pour tout réel $a$ et tout entier $n$, $\left(\mathrm{e}^{a}\right)^{n}$ est égal à :

Réponse : On multiplie les exposants.

5Pour tout réel $a$, $\mathrm{e}^{-a}$ est égal à :

Réponse : $\mathrm{e}^{-a}=\mathrm{e}^{0-a}=\dfrac{1}{\mathrm{e}^{a}}$.

6La fonction exponentielle est la fonction dérivable sur $\mathbb{R}$ telle que :

Réponse : C'est la caractérisation de la fonction exponentielle.

7La dérivée de $x\mapsto\mathrm{e}^{2x}$ est :

Réponse : $\left(\mathrm{e}^{u}\right)'=u'\mathrm{e}^{u}$ avec $u(x)=2x$.

8$\mathrm{e}^{a}=\mathrm{e}^{b}$ équivaut à :

Réponse : La fonction exponentielle est strictement croissante, donc injective.

9Pour tout réel $x$, $\mathrm{e}^{x}$ est :

Réponse : Une exponentielle est toujours strictement positive.

10$\mathrm{e}^{2}\times\mathrm{e}^{-2}$ vaut :

Réponse : $\mathrm{e}^{2-2}=\mathrm{e}^{0}=1$.

11$\mathrm{e}^{0{,}5}\times\mathrm{e}^{0{,}5}$ vaut :

Réponse : $\mathrm{e}^{0{,}5+0{,}5}=\mathrm{e}^{1}=\mathrm{e}$.

12La fonction exponentielle sur $\mathbb{R}$ est :

Réponse : Sa dérivée est $\mathrm{e}^{x}>0$ : elle est strictement croissante.

13Pour tout réel $x$, $\mathrm{e}^{x}>1$ équivaut à :

Réponse : $\mathrm{e}^{x}>\mathrm{e}^{0}$ et la fonction est croissante : $x>0$.

14La dérivée de $x\mapsto\mathrm{e}^{-x}$ est :

Réponse : $\left(\mathrm{e}^{u}\right)'=u'\mathrm{e}^{u}$ avec $u(x)=-x$, d'où $u'=-1$.

15$\left(\mathrm{e}^{x}\right)^{2}$ est égal à :

Réponse : $\left(\mathrm{e}^{x}\right)^{2}=\mathrm{e}^{x\times2}=\mathrm{e}^{2x}$.

16$\mathrm{e}^{3}\times\mathrm{e}^{-5}$ vaut :

Réponse : $\mathrm{e}^{3-5}=\mathrm{e}^{-2}$.

17La courbe de la fonction exponentielle passe par le point :

Réponse : $\mathrm{e}^{0}=1$.

18La dérivée de $x\mapsto x\mathrm{e}^{x}$ est :

Réponse : Formule du produit : $1\times\mathrm{e}^{x}+x\times\mathrm{e}^{x}=(x+1)\mathrm{e}^{x}$.

19L'équation $\mathrm{e}^{x}=1$ a pour solution :

Réponse : $\mathrm{e}^{x}=\mathrm{e}^{0}$ équivaut à $x=0$.

20L'équation $\mathrm{e}^{2x}=\mathrm{e}^{4}$ a pour solution :

Réponse : $2x=4$, donc $x=2$.
