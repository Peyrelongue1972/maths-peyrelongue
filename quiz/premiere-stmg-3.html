Quiz — Généralités sur les fonctions

Première STMG · chapitre 3 · 20 questions

Score : 0 / 20

1On a $f(x)=3x-1$. L'image de $2$ par $f$ est :

Réponse : $f(2)=3\times2-1=5$.

2On a $f(x)=2x+1$. Un antécédent de $7$ par $f$ est :

Réponse : On résout $2x+1=7$, soit $x=3$.

3La fonction $f(x)=-2x+3$ est sur $\mathbb{R}$ :

Réponse : Le coefficient directeur $-2$ est négatif.

4Le coefficient directeur de la fonction affine $f(x)=4x-5$ est :

Réponse : C'est le nombre qui multiplie $x$.

5La représentation graphique d'une fonction affine est :

Réponse : Une fonction affine $f(x)=ax+b$ a pour courbe une droite.

6On a $f(x)=2x-3$. Alors $f(0)$ vaut :

Réponse : $f(0)=2\times0-3=-3$.

7La fonction $f(x)=5x+1$ est sur $\mathbb{R}$ :

Réponse : Son coefficient directeur $5$ est positif.

8La solution de l'équation $3x-6=0$ est :

Réponse : $3x=6$, donc $x=2$.

9Le tableau de signes de $2x-6$ donne :

Réponse : $2x-6=0$ en $x=3$ et le coefficient $2$ est positif.

10Une fonction affine $f(x)=ax+b$ est croissante lorsque :

Réponse : Le signe de $a$ donne le sens de variation.

11La fonction $f(x)=x^{2}$ est-elle affine ?

Réponse : Une fonction affine s'écrit $ax+b$, sans carré.

12L'ordonnée à l'origine de $f(x)=-3x+2$ est :

Réponse : C'est la valeur $b$ dans $ax+b$, donc $f(0)=2$.

13Deux droites non verticales sont parallèles lorsque :

Réponse : Des droites parallèles ont la même pente.

14On a $f(x)=x^{2}-4$. Alors $f(-3)$ vaut :

Réponse : $(-3)^{2}-4=9-4=5$.

15Deux droites non verticales sont perpendiculaires lorsque :

Réponse : C'est la condition d'orthogonalité.

16Graphiquement, les solutions de $f(x)=g(x)$ sont :

Réponse : On cherche les $x$ pour lesquels les deux courbes ont la même ordonnée.

17La fonction $f(x)=3$ est une fonction affine :

Réponse : Une fonction constante est affine de coefficient directeur nul.

18Un nombre peut-il avoir plusieurs antécédents par une fonction ?

Réponse : Par exemple $f(x)=x^{2}$ associe $4$ à l'image de $-2$ et de $2$.

19Le coefficient directeur de la droite passant par $A(0\,;1)$ et $B(2\,;5)$ vaut :

Réponse : $\dfrac{5-1}{2-0}=2$.

20La courbe de $f(x)=2x+1$ passe par le point :

Réponse : $f(0)=1$ : la droite coupe l'axe des ordonnées en $1$.
