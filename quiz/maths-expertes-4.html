Quiz — Les matrices

Maths expertes · chapitre 4 · 20 questions

Score : 0 / 20

1Une matrice $2\times3$ a :

Réponse : Taille $n\times p$ : $n$ lignes, $p$ colonnes.

2On peut multiplier $A$ par $B$ si :

Réponse : Condition de compatibilité.

3Le produit de deux matrices est :

Réponse : $AB\neq BA$ en général.

4La matrice identité $I_n$ vérifie :

Réponse : Élément neutre du produit.

5L'inverse de $A$ existe si :

Réponse : Matrice inversible ⟺ déterminant non nul.

6$\det\begin{pmatrix}a&b\c&d\end{pmatrix}$ vaut :

Réponse : Déterminant $2\times2$.

7Si $\det A=0$, alors $A$ est :

Réponse : Déterminant nul : matrice singulière.

8$(AB)^{-1}$ vaut :

Réponse : L'ordre est inversé.

9$\det(AB)$ vaut :

Réponse : Le déterminant est multiplicatif.

10Une matrice carrée vérifiant $A^{2}=A$ est :

Réponse : Projecteur (idempotent).

11Le système $AX=B$ a une unique solution si :

Réponse : $X=A^{-1}B$.

12La transposée de $\begin{pmatrix}1&2\3&4\end{pmatrix}$ est :

Réponse : On échange lignes et colonnes.

13$\det\begin{pmatrix}1&2\3&4\end{pmatrix}$ vaut :

Réponse : $1\times4-2\times3=-2$.

14L'inverse de $\begin{pmatrix}1&0\0&2\end{pmatrix}$ est :

Réponse : Inverse d'une matrice diagonale.

15Une matrice diagonale est inversible si :

Réponse : On inverse chaque coefficient diagonal.

16Le rang d'une matrice est :

Réponse : Nombre de colonnes indépendantes.

17Deux matrices sont égales si :

Réponse : Égalité coefficient par coefficient.

18La trace d'une matrice carrée est :

Réponse : Somme de la diagonale.

19Un système de Cramer est un système :

Réponse : Solution unique.

20Si $A$ et $B$ sont inversibles, $AB$ est :

Réponse : $(AB)^{-1}=B^{-1}A^{-1}$.
