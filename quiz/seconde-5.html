Quiz — La fonction affine

Seconde · chapitre 5 · 20 questions

Score : 0 / 20

1Une fonction affine s'écrit :

Réponse : C'est la forme générale d'une fonction affine.

2Le coefficient directeur de $f(x)=3x-7$ est :

Réponse : C'est le nombre qui multiplie $x$.

3L'ordonnée à l'origine de $f(x)=-2x+4$ est :

Réponse : C'est la valeur $b$ : $f(0)=4$.

4La fonction $f(x)=5-2x$ est :

Réponse : Son coefficient directeur vaut $-2<0$.

5La courbe représentative d'une fonction affine est :

Réponse : C'est la propriété fondamentale des fonctions affines.

6Pour $f(x)=ax+b$, la valeur $f(0)$ est égale à :

Réponse : $f(0)=a\times0+b=b$.

7On a $f(x)=2x+1$. Alors $f(3)$ vaut :

Réponse : $f(3)=2\times3+1=7$.

8Le coefficient directeur de la droite passant par $A(1\,;2)$ et $B(3\,;8)$ est :

Réponse : $\dfrac{8-2}{3-1}=\dfrac{6}{2}=3$.

9La droite passant par $A(0\,;3)$ et de coefficient directeur $2$ a pour équation :

Réponse : L'ordonnée à l'origine est $f(0)=3$.

10Une fonction affine $f(x)=ax+b$ est croissante lorsque :

Réponse : Le signe de $a$ donne le sens de variation.

11La fonction $f(x)=4$ est :

Réponse : $f(x)=0\times x+4$ : c'est une fonction affine de coefficient directeur nul.

12La solution de $3x-6=0$ est :

Réponse : $3x=6$, donc $x=2$.

13Le signe de $x-3$ est :

Réponse : $x-3=0$ en $x=3$ et le coefficient de $x$ est positif.

14Deux droites non verticales sont parallèles lorsque :

Réponse : Des droites parallèles ont la même pente.

15La droite d'équation $y=-x$ passe par :

Réponse : L'ordonnée à l'origine est nulle.

16On a $f(x)=2x-4$. Alors $f(2)$ vaut :

Réponse : $f(2)=4-4=0$.

17Le signe de $2x-6$ est :

Réponse : $2x-6=0$ en $x=3$ et le coefficient $2$ est positif.

18La droite d'équation $y=-3$ est :

Réponse : Tous ses points ont la même ordonnée.

19Le coefficient directeur d'une droite passant par $A$ et $B$ se calcule par :

Réponse : C'est le rapport de la variation verticale sur l'horizontale.

20On a $f(x)=x+1$. Alors $f(-1)$ vaut :

Réponse : $f(-1)=-1+1=0$.
