Quiz — Les fonctions - limites

Terminale complémentaire · chapitre 2 · 20 questions

Score : 0 / 20

1$\lim\limits_{x\to+\infty}\dfrac{1}{x}$ est :

Réponse : $\dfrac1x\to0$ quand $x\to+\infty$.

2$\lim\limits_{x\to0^{+}}\dfrac{1}{x}$ est :

Réponse : Pour $x>0$ très petit, $\dfrac1x$ devient très grand positif.

3$\lim\limits_{x\to+\infty}\dfrac{2x+1}{x-3}$ est :

Réponse : On factorise par $x$ : $\dfrac{2+\frac1x}{1-\frac3x}\to2$.

4$\lim\limits_{x\to+\infty}\left(x^{2}-3x\right)$ est :

Réponse : Le terme dominant $x^2$ impose sa limite : $+\infty$.

5$\lim\limits_{x\to+\infty}\mathrm{e}^{-x}$ est :

Réponse : $\mathrm{e}^{-x}=\dfrac{1}{\mathrm{e}^{x}}\to0$.

6$\lim\limits_{x\to0}\dfrac{\sin x}{x}$ est :

Réponse : Limite classique (taux d'accroissement de $\sin$ en $0$).

7La droite $y=2$ est asymptote horizontale à $\mathcal{C}_f$ si :

Réponse : Asymptote horizontale en $\pm\infty$ lorsque la limite vaut $2$.

8La droite $x=3$ est asymptote verticale si :

Réponse : Asymptote verticale lorsque la fonction tend vers l'infini en $3$.

9$\lim\limits_{x\to+\infty}\dfrac{\mathrm{e}^{x}}{x}$ est :

Réponse : Croissances comparées : l'exponentielle l'emporte sur $x$.

10$\lim\limits_{x\to+\infty}\dfrac{\ln x}{x}$ est :

Réponse : Croissances comparées : $x$ l'emporte sur $\ln x$.

11$\lim\limits_{x\to+\infty}\left(\sqrt{x}-x\right)$ est :

Réponse : On factorise : $x\left(\dfrac{1}{\sqrt x}-1\right)\to-\infty$.

12Si $\lim_{x\to+\infty}f(x)=3$ et $\lim_{x\to+\infty}g(x)=+\infty$, alors $\lim(f+g)$ est :

Réponse : Somme d'une limite finie et de $+\infty$ : pas d'indétermination, la limite est $+\infty$.

13$\lim\limits_{x\to0}\left(\dfrac1x-\dfrac1{x^{2}}\right)$ est :

Réponse : On réduit : $\dfrac{x-1}{x^{2}}\to-\infty$ quand $x\to0$.

14Une forme indéterminée est :

Réponse : Seules $\frac{\infty}{\infty}$, $\infty-\infty$, $0\times\infty$ et $\frac00$ sont indéterminées.

15$\lim\limits_{x\to-\infty}\mathrm{e}^{x}$ est :

Réponse : L'exponentielle tend vers $0$ en $-\infty$.

16$\lim\limits_{x\to+\infty}\dfrac{3x^{2}-x}{x^{2}+1}$ est :

Réponse : On compare les degrés : rapport des coefficients dominants, $\dfrac31=3$.

17$f(x)=\dfrac{1}{x-2}$. L'ensemble de définition est :

Réponse : Le dénominateur s'annule en $2$.

18Si $f(x)\leqslant g(x)$ et $\lim_{x\to+\infty}g(x)=-\infty$, alors :

Réponse : Théorème de comparaison : $f$ est majorée par une fonction qui tend vers $-\infty$.

19$\lim\limits_{x\to+\infty}\dfrac{\cos x}{x}$ est :

Réponse : On encadre : $-\dfrac1x\leqslant\dfrac{\cos x}{x}\leqslant\dfrac1x$, donc la limite est $0$.

20$\lim\limits_{x\to+\infty}x\,\mathrm{e}^{-x}$ est :

Réponse : $x\mathrm{e}^{-x}=\dfrac{x}{\mathrm{e}^{x}}\to0$ (croissances comparées).
