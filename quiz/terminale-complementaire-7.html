Quiz — Équations différentielles

Terminale complémentaire · chapitre 7 · 20 questions

Score : 0 / 20

1Une équation différentielle est une équation :

Réponse : L'inconnue est une fonction.

2Les solutions de $y'=ay$ sont :

Réponse : Famille de solutions, $C\in\R$.

3Avec $y'=2y$, la solution telle que $f(0)=3$ est :

Réponse : $f(0)=C=3$.

4Avec $y'=-y$, les solutions sont :

Réponse : $a=-1$.

5Une solution particulière constante de $y'=2y+4$ est :

Réponse : $0=2y+4$ donne $y=-2$.

6Les solutions de $y'=ay+b$ sont :

Réponse : Solution générale = homogène + particulière constante $-\frac ba$.

7$y'=3y-6$ : la solution particulière constante est :

Réponse : $0=3y-6$ donne $y=2$.

8Pour l'équation $y''+\omega^{2}y=0$, les solutions font intervenir :

Réponse : Équation de l'oscillateur harmonique.

9La condition initiale permet de :

Réponse : Elle fixe $C$.

10Pour $y''+\omega^{2}y=0$, la solution avec $f(0)=0$ et $f'(0)=1$ est :

Réponse : $f(x)=A\cos+B\sin$ ; $A=0$ et $B\omega=1$.

11Le modèle $y'=ay$ décrit :

Réponse : Croissance si $a>0$, décroissance si $a<0$.

12Dans $y'=0{,}5y$, le temps de doublement est :

Réponse : $\mathrm{e}^{0{,}5t}=2$ donne $t=2\ln2$.

13La désintégration radioactive suit :

Réponse : Décroissance exponentielle.

14Pour $y'=2y+1$, la solution avec $f(0)=0$ est :

Réponse : Solution générale $C\mathrm{e}^{2x}-\frac12$ ; $C=\frac12$.

15Deux solutions de $y'=ay$ diffèrent :

Réponse : $C_1\mathrm{e}^{ax}$ et $C_2\mathrm{e}^{ax}$.

16Si $f$ est solution de $y'=ay+b$, alors $f-\dfrac{\text{particulière}}{}$ est solution de :

Réponse : L'équation homogène associée.

17Pour résoudre $y'=ay+b$, on cherche d'abord :

Réponse : Puis on ajoute la solution de l'équation sans second membre.

18Le modèle de Malthus s'écrit :

Réponse : Croissance exponentielle (illimitée).

19Le modèle de Verhulst s'écrit :

Réponse : Croissance logistique, avec une capacité limite.

20Dans $y'=2y+4$, la limite en $+\infty$ d'une solution non constante est :

Réponse : Autour de la solution constante $-2$, les solutions s'en écartent exponentiellement.
