Quiz — Limite et continuité

Terminale spécialité · chapitre 5 · 20 questions

Score : 0 / 20

1$\lim\limits_{x\to+\infty}\dfrac{1}{x}$ vaut :

Réponse : L'inverse d'un très grand nombre est proche de $0$.

2$\lim\limits_{x\to+\infty}x^{2}$ vaut :

Réponse : Le carré d'un très grand nombre est très grand.

3$\lim\limits_{x\to0^{+}}\dfrac{1}{x}$ vaut :

Réponse : Diviser par un nombre positif très petit donne un très grand nombre.

4Une fonction $f$ est continue en $a$ lorsque :

Réponse : C'est la définition de la continuité en un point.

5Le théorème des valeurs intermédiaires affirme que si $f$ est continue sur $[a\,;b]$ et si $k$ est entre $f(a)$ et $f(b)$, alors :

Réponse : C'est le TVI.

6Si de plus $f$ est strictement monotone sur $[a\,;b]$, le TVI garantit :

Réponse : La stricte monotonie assure l'unicité.

7Une asymptote verticale en $a$ correspond à :

Réponse : La courbe se rapproche d'une droite verticale.

8Une asymptote horizontale d'équation $y=\ell$ correspond à :

Réponse : La courbe se rapproche d'une droite horizontale en l'infini.

9$\lim\limits_{x\to+\infty}\left(1+\dfrac{1}{x}\right)$ vaut :

Réponse : $\dfrac{1}{x}$ tend vers $0$.

10Une forme indéterminée est par exemple :

Réponse : Certaines formes demandent une transformation avant de conclure.

11$\lim\limits_{x\to+\infty}\dfrac{2x+1}{x-3}$ vaut :

Réponse : On divise par $x$ : le quotient tend vers $\dfrac{2}{1}=2$.

12Une fonction dérivable sur un intervalle est :

Réponse : La dérivabilité implique la continuité (la réciproque est fausse).

13Si $f$ est continue sur $[a\,;b]$ et change de signe entre $a$ et $b$, alors :

Réponse : C'est une conséquence du TVI avec $k=0$.

14$\lim\limits_{x\to-\infty}\mathrm{e}^{x}$ vaut :

Réponse : L'exponentielle tend vers $0$ en $-\infty$.

15$\lim\limits_{x\to+\infty}\ln(x)$ vaut :

Réponse : Le logarithme croît lentement mais tend vers $+\infty$.

16La forme $\infty\times0$ est :

Réponse : Il faut transformer l'expression pour conclure.

17$\lim\limits_{x\to1}\dfrac{x^{2}-1}{x-1}$ vaut :

Réponse : On factorise : $\dfrac{(x-1)(x+1)}{x-1}=x+1$, qui tend vers $2$.

18Le TVI permet de démontrer qu'une équation :

Réponse : C'est son usage principal.

19$\lim\limits_{x\to+\infty}\left(3+\dfrac{1}{x^{2}}\right)$ vaut :

Réponse : $\dfrac{1}{x^{2}}$ tend vers $0$.

20Une fonction continue sur un intervalle fermé borné $[a\,;b]$ :

Réponse : C'est le théorème des bornes atteintes.
