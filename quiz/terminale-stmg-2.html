Quiz — Fonction inverse

Terminale STMG · chapitre 2 · 20 questions

Score : 0 / 20

1La fonction inverse est définie sur :

Réponse : On ne peut pas diviser par zéro.

2Pour $f(x)=\dfrac{1}{x}$, on a $f(4)=$

Réponse : $f(4)=\dfrac{1}{4}=0{,}25$.

3Sur $]0\,;+\infty[$, la fonction inverse est :

Réponse : Quand $x$ augmente, $\dfrac{1}{x}$ diminue.

4Sur $]-\infty\,;0[$, la fonction inverse est :

Réponse : Elle est décroissante sur chacun des deux intervalles.

5La courbe de la fonction inverse est :

Réponse : Elle est composée de deux branches.

6La fonction inverse peut-elle s'annuler ?

Réponse : $\dfrac{1}{x}\neq0$ pour tout $x\neq0$.

7Pour $x>0$, $\dfrac{1}{x}$ est :

Réponse : Le quotient de deux nombres positifs est positif.

8Résoudre $\dfrac{1}{x}=2$ revient à résoudre :

Réponse : $\dfrac{1}{x}=2$ donne $x=\dfrac{1}{2}$.

9Comparer $\dfrac{1}{3}$ et $\dfrac{1}{5}$ :

Réponse : La fonction inverse est décroissante sur $]0\,;+\infty[$.

10L'ensemble de définition de $f(x)=\dfrac{1}{x-2}$ est :

Réponse : Le dénominateur s'annule en $x=2$.

11Pour $f(x)=\dfrac{1}{x-2}$, l'image de $3$ est :

Réponse : $f(3)=\dfrac{1}{3-2}=1$.

12Le point $\left(2\,;0{,}5\right)$ appartient-il à la courbe de la fonction inverse ?

Réponse : $f(2)=0{,}5$.

13Une quantité $x$ et son inverse $\dfrac{1}{x}$ ont :

Réponse : Le quotient de deux nombres de même signe est positif.

14$\dfrac{1}{0{,}1}$ vaut :

Réponse : Diviser par $0{,}1$ revient à multiplier par $10$.

15La droite d'équation $y=3$ coupe la courbe de la fonction inverse en :

Réponse : On résout $\dfrac{1}{x}=3$.

16Pour $x$ très grand positif, $\dfrac{1}{x}$ est :

Réponse : L'inverse d'un grand nombre est petit.

17Pour $x$ proche de $0$ par valeurs positives, $\dfrac{1}{x}$ est :

Réponse : Diviser par un nombre très petit donne un grand nombre.

18La fonction inverse est :

Réponse : $\dfrac{1}{-x}=-\dfrac{1}{x}$.

19Résoudre $\dfrac{1}{x}<0$ :

Réponse : L'inverse d'un nombre négatif est négatif.

20Un produit dont le prix $p$ (en €) et la quantité $q$ vérifient $q=\dfrac{1000}{p}$ : si $p=20$, alors :

Réponse : $q=\dfrac{1000}{20}=50$.
