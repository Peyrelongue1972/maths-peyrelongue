Quiz — Variable aléatoire

Première spécialité · chapitre 13 · 20 questions

Score : 0 / 20

1Une variable aléatoire $X$ est :

Réponse : $X$ associe un nombre réel à chaque issue de l'expérience.

2Dans une loi de probabilité $(x_{i}\,;p_{i})$, la somme des $p_{i}$ vaut :

Réponse : Les probabilités des valeurs possibles forment une partition.

3L'espérance $E(X)$ est définie par :

Réponse : C'est la moyenne pondérée des valeurs par leurs probabilités.

4Si $X$ est une variable aléatoire constante égale à $4$, alors $E(X)$ vaut :

Réponse : L'espérance d'une constante est cette constante.

5Pour tous réels $a$ et $b$, $E(aX+b)$ est égal à :

Réponse : L'espérance est linéaire.

6La variance $V(X)$ est définie par :

Réponse : C'est la moyenne des carrés des écarts à l'espérance.

7L'écart type $\sigma(X)$ est égal à :

Réponse : L'écart type est la racine carrée de la variance.

8Un jeu est dit équitable lorsque :

Réponse : Ni le joueur ni l'organisateur n'est avantagé en moyenne.

9On lance un dé équilibré à six faces numérotées de $1$ à $6$. L'espérance de $X$, numéro obtenu, vaut :

Réponse : $E(X)=\dfrac{1+2+3+4+5+6}{6}=\dfrac{21}{6}=3{,}5$.

10Si $X$ prend les valeurs $0$ et $1$ avec $P(X=1)=0{,}7$, alors $E(X)$ vaut :

Réponse : $E(X)=0\times0{,}3+1\times0{,}7=0{,}7$.

11L'espérance d'une variable aléatoire s'interprète comme :

Réponse : C'est la loi des grands nombres : la moyenne se stabilise autour de $E(X)$.

12Pour une variable aléatoire $X$, la variance $V(X)$ est :

Réponse : C'est une moyenne de carrés, donc positive ou nulle.

13Pour tous réels $a$ et $b$, $V(aX+b)$ est égal à :

Réponse : Ajouter $b$ ne change pas la dispersion ; multiplier par $a$ multiplie les carrés par $a^{2}$.

14Si tous les termes d'une variable aléatoire sont égaux, alors $V(X)$ vaut :

Réponse : Aucune dispersion : tous les écarts à l'espérance sont nuls.

15Une loi uniforme sur $\{1\,;2\,;3\,;4\,;5\,;6\}$ attribue à chaque issue la probabilité :

Réponse : Les six issues sont équiprobables.

16L'espérance d'une variable aléatoire $X$ :

Réponse : Par exemple $E(X)=3{,}5$ pour un dé, alors que $X$ ne prend que des entiers.

17Un jeu est favorable au joueur lorsque :

Réponse : Le gain moyen est positif pour le joueur.

18Le gain algébrique d'un jeu se calcule en :

Réponse : Gain algébrique = gain reçu $-$ mise payée.

19L'écart type d'une variable aléatoire s'exprime :

Réponse : Comme il est la racine de la variance, il retrouve l'unité des $x_{i}$.

20On lance deux fois une pièce équilibrée et on note $X$ le nombre de « pile ». Alors $E(X)$ vaut :

Réponse : $X$ suit la loi binomiale de paramètres $n=2$ et $p=0{,}5$ : $E(X)=2\times0{,}5=1$.
