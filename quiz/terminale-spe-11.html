Quiz — Combinatoire et dénombrement

Terminale spécialité · chapitre 11 · 20 questions

Score : 0 / 20

1Pour tout entier $n\geqslant1$, $n!$ vaut :

Réponse : C'est la factorielle de $n$.

2$5!$ vaut :

Réponse : $5!=5\times4\times3\times2\times1=120$.

3$0!$ vaut :

Réponse : Par convention $0!=1$.

4Le coefficient binomial $\dbinom{n}{k}$ vaut :

Réponse : C'est la formule des combinaisons.

5$\dbinom{5}{2}$ vaut :

Réponse : $\dfrac{5!}{2!3!}=\dfrac{120}{12}=10$.

6$\dbinom{n}{0}$ vaut :

Réponse : Il n'y a qu'une façon de ne rien choisir.

7$\dbinom{n}{n}$ vaut :

Réponse : Il n'y a qu'une façon de tout choisir.

8$\dbinom{n}{1}$ vaut :

Réponse : On choisit un élément parmi $n$.

9Au restaurant, $3$ entrées et $4$ plats sont proposés. Le nombre de menus possibles est :

Réponse : Principe multiplicatif : $3\times4=12$.

10Le nombre de codes à $4$ chiffres (de $0$ à $9$) est :

Réponse : Pour chaque position, $10$ choix indépendants.

11Le nombre de permutations de $4$ objets est :

Réponse : $4!=24$.

12$\dbinom{6}{3}$ vaut :

Réponse : $\dfrac{6!}{3!3!}=\dfrac{720}{36}=20$.

13On a la relation :

Réponse : Choisir $k$ revient à écarter $n-k$.

14Le nombre de parties d'un ensemble à $n$ éléments est :

Réponse : Chaque élément est pris ou non.

15La relation de Pascal s'écrit :

Réponse : C'est la construction du triangle de Pascal.

16Le nombre de façons de tirer simultanément $2$ boules parmi $5$ est :

Réponse : $\dbinom{5}{2}=10$.

17Le nombre de façons de choisir $3$ délégués parmi $20$ élèves est :

Réponse : L'ordre n'intervient pas : c'est une combinaison.

18Le nombre d'anagrammes du mot MATH est :

Réponse : Quatre lettres distinctes : $4!=24$.

19Le nombre de mots de $3$ lettres distinctes choisies parmi $5$ est :

Réponse : Arrangements : $5\times4\times3=60$.

20Dans le développement de $(a+b)^{n}$, les coefficients sont :

Réponse : On retrouve la formule du binôme de Newton.
