Terminale spécialité · chapitre 2 · 20 questions

Score : 0 / 20

1La dérivée de $x\mapsto u(ax+b)$ est :

Réponse : On applique la règle de dérivation d'une composée.

2La dérivée de $f(x)=\mathrm{e}^{2x}$ est :

Réponse : $\left(\mathrm{e}^{u}\right)'=u'\mathrm{e}^{u}$.

3La dérivée de $f(x)=\ln(x^{2}+1)$ est :

Réponse : $\left(\ln u\right)'=\dfrac{u'}{u}$.

4La dérivée de $f(x)=\sqrt{3x+1}$ est :

Réponse : $\left(\sqrt{u}\right)'=\dfrac{u'}{2\sqrt{u}}$.

5La dérivée seconde de $f(x)=x^{3}$ est :

Réponse : $f'(x)=3x^{2}$ puis $f''(x)=6x$.

6La dérivée de $f(x)=\left(x^{2}+1\right)^{3}$ est :

Réponse : $\left(u^{n}\right)'=n\,u'\,u^{n-1}$.

7La dérivée de $f(x)=\cos(3x)$ est :

Réponse : $\left(\cos u\right)'=-u'\sin u$.

8La dérivée de $f(x)=x\ln x$ sur $]0\,;+\infty[$ est :

Réponse : Formule du produit : $1\times\ln x+x\times\dfrac{1}{x}$.

9La dérivée de $f(x)=\dfrac{1}{x^{2}+1}$ est :

Réponse : $\left(\dfrac{1}{u}\right)'=-\dfrac{u'}{u^{2}}$.

10La dérivée de $f(x)=\mathrm{e}^{-x}$ est :

Réponse : $u(x)=-x$, donc $u'=-1$.

11Quand $f''(x)>0$ sur un intervalle, la fonction $f$ y est :

Réponse : La dérivée seconde positive correspond à la convexité.

12Un point d'inflexion est un point où :

Réponse : C'est là que la courbe change de concavité.

13La dérivée de $f(x)=\sin(2x)$ est :

Réponse : $\left(\sin u\right)'=u'\cos u$.

14La dérivée de $f(x)=\ln(3x)$ sur $]0\,;+\infty[$ est :

Réponse : $\left(\ln(3x)\right)'=\dfrac{3}{3x}=\dfrac{1}{x}$.

15La dérivée de $f(x)=x\mathrm{e}^{x}$ est :

Réponse : Produit : $1\times\mathrm{e}^{x}+x\times\mathrm{e}^{x}$.

16La dérivée de $f(x)=\sqrt{x^{2}+1}$ est :

Réponse : $\left(\sqrt{u}\right)'=\dfrac{u'}{2\sqrt{u}}$ avec $u'=2x$.

17Si $f''(x)<0$ sur un intervalle, la courbe de $f$ est :

Réponse : La dérivée seconde négative donne la concavité.

18La dérivée de $f(x)=\mathrm{e}^{x^{2}}$ est :

Réponse : $u(x)=x^{2}$, donc $u'=2x$.

19La dérivée troisième de $f(x)=x^{4}$ est :

Réponse : $f'=4x^{3}$, $f''=12x^{2}$, $f'''=24x$.

20La dérivée de $f(x)=\dfrac{\ln x}{x}$ sur $]0\,;+\infty[$ est :

Réponse : Quotient : $\dfrac{\frac{1}{x}\times x-\ln x\times1}{x^{2}}$.
