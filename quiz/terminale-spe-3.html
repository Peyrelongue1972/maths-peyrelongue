Quiz — Limite d'une suite

Terminale spécialité · chapitre 3 · 20 questions

Score : 0 / 20

1Si $u_{n}=\dfrac{1}{n}$ pour $n\geqslant1$, alors $\lim\limits_{n\to+\infty}u_{n}$ vaut :

Réponse : $\dfrac{1}{n}$ tend vers $0$ quand $n$ tend vers $+\infty$.

2La suite définie par $u_{n}=n^{2}$ a pour limite :

Réponse : Les carrés des entiers deviennent arbitrairement grands.

3Une suite qui tend vers $+\infty$ :

Réponse : Une limite infinie signifie que la suite diverge.

4Si $\lim u_{n}=2$ et $\lim v_{n}=3$, alors $\lim(u_{n}+v_{n})$ vaut :

Réponse : On additionne les limites.

5Si $\lim u_{n}=2$ et $\lim v_{n}=3$, alors $\lim(u_{n}\times v_{n})$ vaut :

Réponse : On multiplie les limites.

6Une suite géométrique de raison $q$ avec $|q|<1$ :

Réponse : Les puissances de $q$ tendent vers $0$.

7Une suite géométrique de raison $q>1$ et de premier terme positif :

Réponse : Les puissances de $q$ deviennent arbitrairement grandes.

8La suite $u_{n}=(-1)^{n}$ :

Réponse : Elle oscille entre $-1$ et $1$.

9Si $u_{n}\leqslant v_{n}$ et $\lim u_{n}=+\infty$, alors :

Réponse : C'est le théorème de comparaison.

10Le théorème des gendarmes permet de conclure quand une suite est :

Réponse : Si $u_{n}\leqslant v_{n}\leqslant w_{n}$ et $\lim u_{n}=\lim w_{n}=\ell$, alors $\lim v_{n}=\ell$.

11$\lim\limits_{n\to+\infty}\dfrac{3n+1}{n}$ vaut :

Réponse : On divise par $n$ : $3+\dfrac{1}{n}$ tend vers $3$.

12$\lim\limits_{n\to+\infty}\dfrac{1}{n^{2}}$ vaut :

Réponse : Le dénominateur tend vers $+\infty$.

13Une suite croissante et majorée :

Réponse : C'est le théorème de convergence monotone.

14Une suite décroissante et minorée :

Réponse : Elle est bornée et monotone : elle converge.

15Si $\lim u_{n}=0$ et $\lim v_{n}=0$, alors $\lim(u_{n}\times v_{n})$ vaut :

Réponse : Le produit de deux quantités tendant vers $0$ tend vers $0$.

16La suite $u_{n}=5+\dfrac{2}{n}$ a pour limite :

Réponse : $\dfrac{2}{n}$ tend vers $0$.

17La suite $u_{n}=n-\dfrac{1}{n}$ a pour limite :

Réponse : $n$ tend vers $+\infty$ et $\dfrac{1}{n}$ vers $0$.

18Une suite bornée et monotone :

Réponse : Convergence monotone : toute suite croissante majorée (ou décroissante minorée) converge.

19$\lim\limits_{n\to+\infty}\left(1+\dfrac{1}{n}\right)^{n}$ est :

Réponse : Cette limite définit le nombre $\mathrm{e}$.

20Si une suite converge, alors elle est :

Réponse : Une suite convergente est toujours bornée.
