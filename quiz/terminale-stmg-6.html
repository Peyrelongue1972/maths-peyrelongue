1$\log(1)$ vaut :

Réponse : $\log(1)=0$.

2$\log(10)$ vaut :

Réponse : Le logarithme décimal de $10$ vaut $1$.

3$\log(100)$ vaut :

Réponse : $100=10^{2}$, donc $\log(100)=2$.

4Pour tous réels $a>0$ et $b>0$, $\log(ab)$ vaut :

Réponse : Le logarithme transforme le produit en somme.

5Pour tous réels $a>0$ et $b>0$, $\log\left(\dfrac{a}{b}\right)$ vaut :

Réponse : Le quotient devient une différence.

6Pour tout $a>0$ et tout entier $n$, $\log\left(a^{n}\right)$ vaut :

Réponse : La puissance devient un facteur.

7La fonction logarithme décimal est définie sur :

Réponse : On ne prend le logarithme que de nombres strictement positifs.

8$\log(1000)$ vaut :

Réponse : $1000=10^{3}$.

9$\log(0{,}1)$ vaut :

Réponse : $0{,}1=10^{-1}$.

10$\log(2)+\log(5)$ vaut :

Réponse : $\log(2)+\log(5)=\log(10)=1$.

11$\log\left(\sqrt{10}\right)$ vaut :

Réponse : $\sqrt{10}=10^{0{,}5}$.

12Pour tout réel $x>0$, $10^{\log(x)}$ vaut :

Réponse : Les fonctions $x\mapsto10^{x}$ et $\log$ sont réciproques.

13Pour tout réel $x$, $\log\left(10^{x}\right)$ vaut :

Réponse : Ce sont deux fonctions réciproques.

14Sur $]0\,;+\infty[$, la fonction logarithme décimal est :

Réponse : Elle croît lentement mais toujours.

Réponse : $x=10^{2}=100$.

16$\log(0{,}01)$ vaut :

Réponse : $0{,}01=10^{-2}$.

17$\log(4)$ vaut :

Réponse : $4=2^{2}$, donc $\log(4)=2\log(2)$.

Réponse : C'est la définition du pH.
