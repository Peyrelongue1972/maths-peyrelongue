Quiz — Fonction logarithme népérien

Terminale spécialité · chapitre 6 · 20 questions

Score : 0 / 20

1$\ln(1)$ vaut :

Réponse : $\ln(1)=0$.

2$\ln(\mathrm{e})$ vaut :

Réponse : $\ln(\mathrm{e})=1$.

3Pour tous réels $a>0$ et $b>0$, $\ln(ab)$ vaut :

Réponse : Le logarithme transforme le produit en somme.

4Pour tous réels $a>0$ et $b>0$, $\ln\left(\dfrac{a}{b}\right)$ vaut :

Réponse : Le quotient devient une différence.

5Pour tout $a>0$ et tout entier $n$, $\ln(a^{n})$ vaut :

Réponse : La puissance devient un facteur.

6Pour tout $a>0$, $\ln\left(\dfrac{1}{a}\right)$ vaut :

Réponse : $\ln(1)-\ln(a)=-\ln(a)$.

7La fonction logarithme népérien est définie sur :

Réponse : On ne prend le logarithme que de nombres strictement positifs.

8La dérivée de $\ln(x)$ sur $]0\,;+\infty[$ est :

Réponse : C'est la dérivée de référence.

9Sur $]0\,;+\infty[$, la fonction $\ln$ est :

Réponse : Sa dérivée $\dfrac{1}{x}$ est positive.

10Pour tout réel $x$, $\ln\left(\mathrm{e}^{x}\right)$ vaut :

Réponse : Les fonctions $\ln$ et $\exp$ sont réciproques.

11Pour tout réel $x>0$, $\mathrm{e}^{\ln(x)}$ vaut :

Réponse : Ce sont deux fonctions réciproques.

12$\ln(2)+\ln(3)$ vaut :

Réponse : $\ln(2\times3)=\ln(6)$.

13$\ln(8)$ vaut :

Réponse : $8=2^{3}$, donc $\ln(8)=3\ln(2)$.

14L'équation $\ln(x)=0$ a pour solution :

Réponse : $\ln(1)=0$.

15L'inéquation $\ln(x)<0$ a pour ensemble de solutions :

Réponse : $\ln$ est croissante et $\ln(1)=0$.

16$\lim\limits_{x\to0^{+}}\ln(x)$ vaut :

Réponse : La courbe admet l'axe des ordonnées pour asymptote verticale.

17$\ln\left(\sqrt{2}\right)$ vaut :

Réponse : $\sqrt{2}=2^{1/2}$, donc $\ln\left(\sqrt2\right)=\dfrac{1}{2}\ln 2$.

18$\ln\left(\mathrm{e}^{2}\right)$ vaut :

Réponse : $\ln\left(\mathrm{e}^{2}\right)=2$.

19La dérivée de $\ln(2x)$ sur $]0\,;+\infty[$ est :

Réponse : $\ln(2x)=\ln(2)+\ln(x)$, de dérivée $\dfrac{1}{x}$.

20Pour $a>0$ et $b>0$, l'égalité $\ln(ab)=\ln(a)\times\ln(b)$ est :

Réponse : La bonne formule est $\ln(ab)=\ln(a)+\ln(b)$.
