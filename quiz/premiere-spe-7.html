Quiz — Suites arithmétiques et géométriques

Première spécialité · chapitre 7 · 20 questions

Score : 0 / 20

1Pour une suite arithmétique de raison $r$, le terme général est :

Réponse : On ajoute $r$ à chaque pas : $u_{n}=u_{0}+n\times r$.

2Une suite arithmétique a pour premier terme $u_{0}=3$ et pour raison $5$. Alors $u_{10}$ vaut :

Réponse : $u_{10}=3+10\times5=53$.

3La somme des $n$ premiers termes d'une suite arithmétique vaut :

Réponse : C'est la moyenne du premier et du dernier terme, multipliée par le nombre de termes.

4Pour une suite géométrique de raison $q$, le terme général est :

Réponse : On multiplie par $q$ à chaque pas : $u_{n}=u_{0}\times q^{n}$.

5Une suite géométrique a pour premier terme $u_{0}=2$ et pour raison $3$. Alors $u_{4}$ vaut :

Réponse : $u_{4}=2\times3^{4}=2\times81=162$.

6Une suite arithmétique vérifie $u_{3}=7$ et $u_{8}=22$. Sa raison est :

Réponse : $u_{8}-u_{3}=5r=15$, donc $r=3$.

7Une suite géométrique vérifie $v_{2}=6$ et $v_{4}=54$. Sa raison $q$ (positive) est :

Réponse : $v_{4}=v_{2}\times q^{2}$, donc $q^{2}=9$ et $q=3$.

8La somme $1+3+9+27+81$ vaut :

Réponse : C'est une somme géométrique de raison $3$ : $\dfrac{1-3^{5}}{1-3}=121$.

9Une suite arithmétique est strictement croissante lorsque :

Réponse : $u_{n+1}-u_{n}=r>0$ : chaque terme dépasse le précédent.

10Une suite géométrique de premier terme positif et de raison $0{,}9$ est :

Réponse : $00$ : les termes diminuent.

11La somme $1+2+3+\cdots+n$ vaut :

Réponse : C'est la somme des $n$ premiers entiers.

12On a $u_{n}=4n-1$. Alors $u_{0}$ vaut :

Réponse : $u_{0}=4\times0-1=-1$.

13Une suite géométrique de raison $-2$ et de premier terme positif :

Réponse : Multiplier par un nombre négatif change le signe à chaque pas.

14Pour une suite géométrique, la relation entre deux termes consécutifs est :

Réponse : C'est la définition d'une suite géométrique de raison $q$.

15Pour une suite arithmétique, $u_{n+1}-u_{n}$ est égal à :

Réponse : La différence entre deux termes consécutifs est constante, égale à la raison.

16On a $u_{0}=1$ et $u_{n+1}=2u_{n}+1$. Alors $u_{3}$ vaut :

Réponse : $u_{1}=3$, $u_{2}=7$, $u_{3}=15$.

17La somme $1+2+4+8+\cdots+2^{n}$ vaut :

Réponse : Somme géométrique de raison $2$ : $\dfrac{1-2^{n+1}}{1-2}=2^{n+1}-1$.

18La suite définie par $u_{n}=5-n$ est :

Réponse : C'est une suite arithmétique de raison $-1$.

19Une suite géométrique de raison $1$ est :

Réponse : $u_{n+1}=1\times u_{n}$ : tous les termes sont égaux.

20Une suite arithmétique a pour terme général $u_{n}=7-2n$. Sa raison est :

Réponse : Le coefficient de $n$ est la raison : $r=-2$.
