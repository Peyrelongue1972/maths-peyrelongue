Quiz — Les suites : généralités

Première spécialité · chapitre 3 · 20 questions

Score : 0 / 20

1Une suite $(u_{n})$ est une fonction définie sur :

Réponse : Les termes sont numérotés par des entiers : $u_{0}$, $u_{1}$, $u_{2}$…

2On considère la suite définie par $u_{n}=2n+1$. Son terme d'indice $3$ est :

Réponse : $u_{3}=2\times3+1=7$.

3Dire qu'une suite est définie par récurrence signifie que :

Réponse : Le terme suivant se calcule à partir du précédent : c'est une définition par récurrence.

4On a $u_{0}=2$ et $u_{n+1}=3u_{n}$. Alors $u_{2}$ vaut :

Réponse : $u_{1}=3\times2=6$ puis $u_{2}=3\times6=18$.

5La suite définie sur $\mathbb{N}^{*}$ par $u_{n}=\dfrac{1}{n}$ est :

Réponse : $u_{n+1}-u_{n}=\dfrac{1}{n+1}-\dfrac{1}{n}<0$ : les termes diminuent.

6La suite définie sur $\mathbb{N}$ par $u_{n}=n^{2}$ est :

Réponse : $u_{n+1}-u_{n}=2n+1>0$ : la suite est strictement croissante.

7La suite définie par $u_{n}=(-1)^{n}$ est :

Réponse : Ses termes valent alternativement $1$ et $-1$ : elle n'est ni croissante ni décroissante.

8Dire qu'une suite $(u_{n})$ est majorée signifie que :

Réponse : Il existe un réel $M$ tel que $u_{n}\leqslant M$ pour tout $n$.

9Une suite constante est :

Réponse : Tous les termes sont égaux : $u_{n+1}-u_{n}=0$, donc $u_{n+1}\geqslant u_{n}$ et $u_{n+1}\leqslant u_{n}$.

10On considère la suite $u_{n}=3n-5$. Alors $u_{4}$ vaut :

Réponse : $u_{4}=3\times4-5=12-5=7$.

11Si pour tout $n$ on a $u_{n+1}-u_{n}<0$, alors la suite est :

Réponse : Chaque terme est strictement inférieur au précédent.

12La représentation graphique d'une suite est :

Réponse : On place les points de coordonnées $(n\,;u_{n})$ : ils sont isolés, pas reliés.

13On a $u_{0}=1$ et $u_{n+1}=u_{n}+2$. Alors $u_{3}$ vaut :

Réponse : $u_{1}=3$, $u_{2}=5$, $u_{3}=7$.

14Une suite définie par une formule du type $u_{n}=f(n)$ est dite définie :

Réponse : On calcule directement $u_{n}$ à partir de $n$.

15La suite définie par $u_{n}=5$ pour tout $n$ est :

Réponse : Tous ses termes valent $5$.

16Une suite est bornée lorsque :

Réponse : Il existe deux réels $m$ et $M$ tels que $m\leqslant u_{n}\leqslant M$ pour tout $n$.

17On considère $u_{n}=2n+1$. Alors $u_{n+1}$ est égal à :

Réponse : On remplace $n$ par $n+1$ : $u_{n+1}=2(n+1)+1=2n+3$.

18La suite définie sur $\mathbb{N}$ par $u_{n}=\dfrac{1}{2^{n}}$ est :

Réponse : Chaque terme est la moitié du précédent : les termes diminuent.

19Si pour tout $n$ on a $0\leqslant u_{n}\leqslant1$, alors la suite est :

Réponse : Elle est minorée par $0$ et majorée par $1$.

20Pour une suite définie sur $\mathbb{N}^{*}$, le premier terme est :

Réponse : L'ensemble de définition est $\mathbb{N}^{*}=\{1\,;2\,;3\,;\dots\}$, donc le premier indice est $1$.
