1Une démonstration par récurrence comporte :

Réponse : Les deux étapes sont indispensables.

2La dérivée de $\mathrm{e}^{2x}$ est :

Réponse : Dérivation d'une composée.

3$\lim\limits_{n\to+\infty}\dfrac{1}{n}$ vaut :

Réponse : L'inverse d'un grand entier tend vers $0$.

4$\ln(ab)$ vaut, pour $a>0$ et $b>0$ :

Réponse : Le logarithme transforme le produit en somme.

5Une primitive de $x^{2}$ est :

Réponse : On dérive pour vérifier.

6Les solutions de $y'=3y$ sont :

Réponse : Forme générale $C\mathrm{e}^{ax}$.

7Une suite croissante et majorée :

Réponse : Théorème de convergence monotone.

8Un vecteur normal au plan $2x-y+3z-1=0$ est :

Réponse : Les coefficients de $x$, $y$, $z$.

9$\dbinom{5}{2}$ vaut :

Réponse : $\dfrac{5!}{2!3!}=10$.

10La dérivée de $\sin(x)$ est :

Réponse : Dérivée usuelle.

11$\displaystyle\int_0^1 2x\,\mathrm{d}x$ vaut :

Réponse : $\left[x^{2}\right]_0^1=1$.

12$X$ suit $\mathcal{B}(10\,;0{,}2)$. Alors $E(X)$ vaut :

Réponse : $E(X)=np=2$.

13Pour $X$ et $Y$ indépendantes, $V(X+Y)$ vaut :

Réponse : Les variances s'additionnent.

14Si $f$ est continue sur $[a\,;b]$ et $f(a)f(b)<0$, alors l'équation $f(x)=0$ admet :

Réponse : C'est le théorème des valeurs intermédiaires.

15Le nombre de façons de choisir $2$ délégués parmi $6$ est :

Réponse : $\dbinom{6}{2}=15$.

16La dérivée de $\ln(x)$ est :

Réponse : Dérivée de référence.

17Une primitive de $\mathrm{e}^{x}$ est :

Réponse : L'exponentielle est sa propre primitive.

18$\lim\limits_{x\to+\infty}\dfrac{2x+1}{x-3}$ vaut :

Réponse : On compare les termes de plus haut degré.

19$P(X=0)$ pour $X\sim\mathcal{B}(n\,;p)$ vaut :

Réponse : Aucun succès sur $n$ épreuves.

20$\displaystyle\int_1^{\mathrm{e}}\dfrac{1}{x}\,\mathrm{d}x$ vaut :

Réponse : $\left[\ln x\right]_1^{\mathrm{e}}=1$.
