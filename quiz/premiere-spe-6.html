1$\cos\left(\dfrac{\pi}{3}\right)$ vaut :

Réponse : Le point image de $\dfrac{\pi}{3}$ a pour abscisse $\dfrac{1}{2}$.

2$\sin\left(\dfrac{\pi}{6}\right)$ vaut :

Réponse : $\sin\left(\dfrac{\pi}{6}\right)=\dfrac{1}{2}$.

3$\cos\left(\dfrac{\pi}{4}\right)$ vaut :

Réponse : $\cos\left(\dfrac{\pi}{4}\right)=\sin\left(\dfrac{\pi}{4}\right)=\dfrac{\sqrt{2}}{2}$.

4$\sin\left(\dfrac{\pi}{2}\right)$ vaut :

Réponse : Le point image de $\dfrac{\pi}{2}$ est $(0\,;1)$.

5$\cos(\pi)$ vaut :

Réponse : Le point image de $\pi$ est $(-1\,;0)$.

6Pour tout réel $x$, $\cos(-x)$ est égale à :

Réponse : La fonction cosinus est paire.

7Pour tout réel $x$, $\sin(-x)$ est égale à :

Réponse : La fonction sinus est impaire.

8Pour tout réel $x$, $\cos(x+2\pi)$ est égale à :

Réponse : La fonction cosinus est $2\pi$-périodique.

9Pour tout réel $x$, $\sin(\pi-x)$ est égale à :

Réponse : Les points d'abscisses $x$ et $\pi-x$ ont la même ordonnée.

10Pour tout réel $x$, $\cos\left(\dfrac{\pi}{2}-x\right)$ est égale à :

Réponse : Angles complémentaires : $\cos\left(\dfrac{\pi}{2}-x\right)=\sin(x)$.

11$\sin\left(\dfrac{5\pi}{6}\right)$ vaut :

Réponse : $\sin\left(\dfrac{5\pi}{6}\right)=\sin\left(\pi-\dfrac{\pi}{6}\right)=\sin\left(\dfrac{\pi}{6}\right)=\dfrac{1}{2}$.

12$\cos\left(\dfrac{2\pi}{3}\right)$ vaut :

Réponse : $\cos\left(\dfrac{2\pi}{3}\right)=-\cos\left(\dfrac{\pi}{3}\right)=-\dfrac{1}{2}$.

13$\sin\left(\dfrac{3\pi}{4}\right)$ vaut :

Réponse : $\sin\left(\dfrac{3\pi}{4}\right)=\sin\left(\pi-\dfrac{\pi}{4}\right)=\dfrac{\sqrt{2}}{2}$.

14Le point image de $\dfrac{3\pi}{2}$ a pour coordonnées :

Réponse : $\cos\left(\dfrac{3\pi}{2}\right)=0$ et $\sin\left(\dfrac{3\pi}{2}\right)=-1$.

15Pour tout réel $x$, $\cos^{2}(x)+\sin^{2}(x)$ vaut :

Réponse : Le point image est sur le cercle unité : $x^{2}+y^{2}=1$.

16$\cos\left(-\dfrac{\pi}{3}\right)$ vaut :

Réponse : La fonction cosinus est paire : $\cos\left(-\dfrac{\pi}{3}\right)=\cos\left(\dfrac{\pi}{3}\right)=\dfrac{1}{2}$.

17$\sin\left(\dfrac{\pi}{3}\right)$ vaut :

Réponse : $\sin\left(\dfrac{\pi}{3}\right)=\dfrac{\sqrt{3}}{2}$.

18$\cos\left(\dfrac{\pi}{6}\right)$ vaut :

Réponse : $\cos\left(\dfrac{\pi}{6}\right)=\dfrac{\sqrt{3}}{2}$.

19Les réels $\dfrac{\pi}{4}$ et $\dfrac{9\pi}{4}$ sont associés :

Réponse : $\dfrac{9\pi}{4}=\dfrac{\pi}{4}+2\pi$ : c'est le même point.

20L'équation $\sin(x)=0$ a pour solutions :

Réponse : Le sinus s'annule sur l'axe des abscisses, c'est-à-dire tous les $\pi$.
