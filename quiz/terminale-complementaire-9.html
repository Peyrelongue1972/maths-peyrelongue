Terminale complémentaire · chapitre 9 · 20 questions

Score : 0 / 20

1L'intégrale $\displaystyle\int_0^1 x\,\mathrm dx$ vaut :

Réponse : $\left[\dfrac{x^{2}}{2}\right]_0^1=\dfrac12$.

2$\displaystyle\int_1^{\mathrm e}\frac{1}{x}\,\mathrm dx$ vaut :

Réponse : $[\ln x]_1^{\mathrm e}=1$.

3Une primitive de $x\mapsto x^{3}$ est :

Réponse : On augmente l'exposant et on divise.

4Une primitive de $\dfrac{1}{x}$ sur $]0\,;+\infty[$ est :

Réponse : La dérivée de $\ln$ est $\dfrac1x$.

5$\displaystyle\int_0^{1}\mathrm{e}^{x}\,\mathrm dx$ vaut :

Réponse : $[\mathrm{e}^{x}]_0^1=\mathrm{e}-1$.

6La valeur moyenne de $f$ sur $[a\,;b]$ est :

Réponse : Définition de la valeur moyenne.

7Si $f\geqslant0$ sur $[a\,;b]$, $\displaystyle\int_a^b f$ est :

Réponse : Interprétation géométrique (en unités d'aire).

8Si $f\leqslant0$ sur $[a\,;b]$, alors $\displaystyle\int_a^b f$ est :

Réponse : L'intégrale compte le signe (aire algébrique).

9$\displaystyle\int_a^a f$ vaut :

Réponse : Intervalle de longueur nulle.

10La relation de Chasles donne :

Réponse : Additivité par rapport à l'intervalle.

11$\displaystyle\int_a^b f=-\displaystyle\int_b^a f$ :

Réponse : On inverse les bornes en changeant de signe.

12Toute fonction continue sur $[a\,;b]$ admet :

Réponse : Les primitives diffèrent d'une constante.

13La dérivée de $\displaystyle\int_a^x f(t)\,\mathrm dt$ est :

Réponse : Théorème fondamental.

14$\displaystyle\int_0^{1}2x\,\mathrm dx$ vaut :

Réponse : $[x^{2}]_0^1=1$.

15L'aire entre deux courbes $f\geqslant g$ sur $[a\,;b]$ est :

Réponse : Différence des aires, donc intégrale de la différence.

16Une intégrale s'exprime en :

Réponse : u.a. (unités d'aire).

17Si $f\leqslant g$ sur $[a\,;b]$, alors :

Réponse : Conservation de l'ordre par l'intégrale.

18$\displaystyle\int_1^2 \dfrac{1}{x^{2}}\,\mathrm dx$ vaut :

Réponse : $\left[-\dfrac1x\right]_1^2=\dfrac12$.

19Une primitive de $x\mapsto\cos x$ est :

Réponse : $(\sin x)'=\cos x$.

20$\displaystyle\int_0^{\pi}\sin x\,\mathrm dx$ vaut :

Réponse : $[-\cos x]_0^{\pi}=1+1=2$.
