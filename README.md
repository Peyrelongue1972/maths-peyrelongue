# Site de mathématiques — Frederik de Peyrelongue

Cours, TD, fiches méthodes, activités et quiz interactifs pour les niveaux
Seconde, Première spécialité, Première STMG, Terminale spécialité,
Terminale complémentaire, Terminale STMG, Maths expertes et Prépa à la prépa.

## Publication sur GitHub Pages

1. Créer un dépôt **Public** (par exemple `maths-peyrelongue`).
2. Déposer **tout le contenu de ce dossier** à la racine du dépôt
   (`index.html`, `assets/`, `img/`, `pdf/`, `quiz/`, `.nojekyll`, `README.md`).
3. *Settings* → *Pages* → *Source* : `Deploy from a branch`,
   *Branch* : `main`, dossier `/ (root)` → **Save**.
4. Le site est publié à l'adresse `https://<compte>.github.io/maths-peyrelongue/`
   (compter 1 à 2 minutes).

## Remarques

- `.nojekyll` est indispensable (GitHub ignorerait sinon certains fichiers).
- Les liens sont relatifs : le site fonctionne aussi bien en local qu'en ligne.
- L'accès est protégé par un mot de passe (`assets/acces.js`) : cette protection
  est **dissuasive**, elle n'empêche pas l'ouverture directe d'un PDF par son URL.
- Le site est généré automatiquement (index, chapitres, quiz) : ne pas renommer
  `index.html`, `assets`, `img`, `pdf` ni `quiz`.
